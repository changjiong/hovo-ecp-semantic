## 语义政策

### M.P.IDENTITY

适用：M.C.PARTY, M.C.PERSON, M.C.SUBJECT, M.C.RIGHT, M.C.POSITION。依据：K.R.03, K.R.05, K.R.08, K.R.09, K.R.13。

- 新增相同证据或重复来源 → 保持同一业务事实身份，增加证据关联。
- 名称、证件更换或角色退出 → 核实身份延续，角色和有效期间变化单独记录。
- 国内分支与所属主体 → 保持两个主体身份，并按前提判断名单沿用和本行尽调复用。

未知：身份不足时保留候选匹配，不强行合并。

冲突：并列冲突身份及核实任务，不自行采用接口旧字段顺序。

禁止：不得将同名、相同头衔或重复材料当作身份充分证明。

### M.P.INTERVAL

适用：M.C.RIGHT, M.C.RELATION, M.C.QUALIFICATION, M.C.EVENT, M.C.CONTEXT。依据：K.R.11, K.R.11.START, K.R.11.HISTORY。

- 法律关系附条件生效 → 核对条件满足证据后确定实际生效时点；签署与录入日不代替。
- 同一人同一主体各资格有效区间在边界相接且证明无空档 → 合并总体连续区间，总体起点不重置，各类型形成终止仍各自保存。
- 所有资格实际中断后再次满足 → 旧总体区间终止，当前形成日期取最新区间起点，回访展示旧区间和中断。

未知：只有日期而无法证明同日先后和连续时，不从同日推定无空档；补证。

冲突：保留不同证据所述时点，核实有效约定与条件，不用最新录入覆盖历史。

禁止：不得用历史最早达标日、查询日或无证据连续性替代当前日期。

### M.P.DEADLINES

适用：M.C.OBLIGATION, M.C.EVENT, M.C.DIFFERENCE。依据：K.R.12, K.R.18, K.R.19, K.R.21。

- 实际信息变化或免报条件失效 → 从实际事件起按备案30日义务记录，不解释为差异容差。
- 差异报告或非重大记录提示 → 按相应30个工作日要求和各自起算依据记录，不能由备案期顺延。
- 存量或不动户例外 → 保留适用生效日、风险分层和激活办理触发；延期不是豁免。

未知：起算事件、工作日日历或例外不明时明确截止计算待核，不写猜测日期。

冲突：不同义务分别成立，不用最长期限覆盖最短义务。

禁止：不得把日与工作日混用，或把30日当日期差异允许区间。

### M.P.CLOSURE

适用：M.C.DIFFERENCE, M.C.REPORT, M.C.REQUEST, M.C.RECEIPT, M.C.VERIFICATION。依据：K.R.19, K.R.19.CLOSE, K.R.24.STATUS。

- 客户已实际更正且机构重新查询复核相关要素一致 → 差异可记已解决，并保留更正、复核、旧报告及应履行义务。
- 仅提交更正申请或仅报告办结/终止 → 保持差异待核实或待复核，不自动闭环。
- 机构自身错误已纠正并重新核实一致 → 保留自身更正依据与复核记录，避免误归客户错误。

未知：未取得复核结果就保持待复核。

冲突：报告终止但仍遗漏人员时继续差异处理。

禁止：客户口头承诺、系统受理和报告终止均不能代替实质解决。

### M.P.FEEDBACK

适用：M.C.REQUEST, M.C.RECEIPT, M.C.REPORT, M.C.CASE_APPLICATION, M.C.PARAMETER。依据：K.R.23, K.R.24。

- 只取得初校或编号 → 保持待业务结果或待审批，并关联原请求和逐户对象。
- 获得相应最终反馈 → 按该事项的允许状态推进，报告状态不传播为差异解决。
- 参数缺期或系统非受理 → 保留待补参数或待发送，不制造成功反馈。

未知：无反馈不得推成功；重复拒绝后核实首次请求。

冲突：相矛盾反馈连同时间和对象保存并核实。

禁止：初校成功、附件可用和案例受理不等于报告或案例获批。

### M.P.REVIEW

适用：M.C.EVENT, M.C.TASK, M.C.RIGHT, M.C.DECISION, M.C.OBLIGATION。依据：K.R.12, K.R.16, K.R.19。

- 协议、权利或可能影响UBO的职责变化 → 记录事件、生效证据和旧结论，启动影响评估，必要时更新。
- 普通董事变动但无控制、权利和风险影响 → 记录评估，可不更新正式UBO信息。
- 近期变化时点性待更新 → 建立跟踪事项，责任人、复核时点和超期升级尚待确认则保持空缺标识。

未知：变化内容不完整时请求材料，不默认未变化。

冲突：历史更正保留原判断及获知时间，不重写当时所知。

禁止：不得给所有客户虚设统一周期或替代未确认责任分工。

### M.P.RIGHTS

适用：M.C.RIGHT, M.C.PATH, M.C.RELATION。依据：K.R.03, K.R.04, K.R.05。

- 已核实普通无环同维度路径 → 逐路径相乘，同一自然人有效多路径去重后相加；25%包含本数。
- 股权、收益和表决权分别存在 → 分别计算；不能把10%股权与20%表决权相加。
- 存在循环、交叉、截断或未明归属 → 停止确定精确总比及完整清单，保留已知候选并加强核实。
- 同一人已满足标准一 → 备案分类按标准一，继续保留原始其他权利事实；标准二与三同时成立可同时记录。

未知：缺失不是0，算法未确认不设循环截断为正式口径。

冲突：接口>25%不改写制度>=25%；报送适配列缺口。

禁止：不得先舍入再判断达标，或一人达标后停止识别其他人。

### M.P.FX

适用：M.A.CAPITAL, M.C.DECISION。依据：K.R.02。

- 人民币出资且四项免报条件均核实 → 金额<=1000万元才满足金额条件。
- 外币边界缺折算规则 → 折算日期、汇率与舍入待确认，返回证据不足。

## 建模取舍

### M.D.IDENTITY · UBO是人的永久类型吗？

候选：将人标成永久UBO；将人对主体在某场景某期间的资格建模

选择：采用自然人、类型资格及总体区间分离。

依据：同一人对不同主体、期间和标准存在不同结论。

后果：不重复计人，能解释退出、重入和跨类型连续。

### M.D.INTERVAL · 总体形成日期如何与类型日期共存？

候选：仅保存一个日期；只保存每种类型日期；类型区间加总体连续区间

选择：类型关系与总体连续资格分别记录。

依据：K.R.11与用户已答连续性口径；生效证据缺失仍未知。

后果：总体连续不重置，真实中断重开，回访可追溯；同日不证明连续的情况需补证。

### M.D.PURPOSE · 备案免报、免识别和简化能合成一个豁免标志吗？

候选：合为统一豁免；按责任主体和用途分别判断

选择：分别建模。

依据：K.R.01、K.R.02、K.R.15的职责和条件不同。

后果：一个主体可能当前无需备案但仍需银行识别，不相互推导。

### M.D.FACT · 权利事实、备案分类与机构判断是否合并？

候选：合成单个UBO表述；保留权利事实、资格与判断/核实记录

选择：三类业务含义分开。

依据：标准一备案优先不能丢掉实际收益表决事实；核实也有独立证据责任。

后果：材料更新不自动覆盖原结论，模型可容纳未知与冲突。

### M.D.DIFFERENCE · 重大性与近期更新能做成互斥三选一吗？

候选：重大/非重大/时点性三选一；重大性和待更新标记分别记录

选择：两个独立维度。

依据：K.R.18.PENDING：30日不是容差，年月差异独立重大。

后果：近期变化也可能重大；责任未定的跟踪事项保留待确认。

### M.D.CLOSURE · 报告办结是否代表差异解决？

候选：共用一个状态；报告状态、请求阶段与差异实质状态分开

选择：三个对象分别迁移。

依据：K.R.19.CLOSE和K.R.24.STATUS明确需实际更正加复核一致。

后果：终止/撤销/办结不能抹去仍然存在的差异。

### M.D.INTERFACE · BOMIS字段是否成为领域概念？

候选：每个字段和错误码定义一个概念；只承接办理意图、参数适用、反馈阶段和义务含义

选择：保留业务对象与状态，技术字段映射留给后续工程。

依据：模型应在更换信息系统后仍可解释业务。

后果：Q23/Q24有业务落点但不承诺全部接口格式或安全传输实现。

### M.D.DRAFT · 未完成全量语义审查的04能否试建？

候选：拒绝所有建模；默认为已确认输入；固定待审版本并逐项传递限制

选择：在用户本次先产出一版授权下建立DRAFT模型。

依据：04结构PASS但业务确认PENDING、语义PARTIAL。

后果：可评审，不可宣称制度全量无遗漏或正式下游交接；变更需新版本。
