# A01受益所有人业务领域模型：业务审阅稿

领域：受益所有人识别

以纯业务视角表达自然人、组织、分支、信托、资管产品之间的权益、收益、表决、控制、角色和有效时间关系，以及据此形成受益所有人人选的稳定业务判断；备案流程、BOMIS差异报告、AML风险治理和机构审批仅作为外部上下文或范围边界。

## 业务世界总览

### 业务对象

| 业务对象 | 类别 | 业务定义 |
| --- | --- | --- |
| 自然人 | 业务参与方 | 能够以个人身份承担权益、控制或业务角色，并且只有自然人才可能成为最终受益所有人。 |
| 组织主体 | 业务参与方 | 公司、合伙企业、社会组织等具有独立组织身份、可承载权益和治理关系的非自然人主体。 |
| 分支机构 | 业务对象 | 依附于所属组织、但在特定规则下具有独立识别语义的境内分支或外国公司中国分支。 |
| 信托 | 业务对象 | 由委托人、受托人、受益人、监察人及其他最终控制权安排共同构成的信托关系对象。 |
| 资产管理产品 | 业务对象 | 需要根据产品权利结构、管理受托关系、募集备案和风险判断受益所有人的资产管理产品。 |
| 识别证据 | 业务证据 | 用于支持或质疑自然人身份、业务关系、角色、有效期间或业务判断的可追溯来源材料。 |

### 业务关系

| 业务关系 | 参与对象 | 业务定义 |
| --- | --- | --- |
| 自然人直接权益关系 | 自然人持有人→自然人；权益所及组织→组织主体 | 自然人在特定期间直接持有组织的股权、股份或合伙权益。 |
| 组织间权益关系 | 持有人组织→组织主体；被持有组织→组织主体 | 一个组织在特定期间直接持有另一个组织的股权、股份或合伙权益。 |
| 最终收益权关系 | 收益权自然人→自然人；目标组织→组织主体 | 自然人在特定期间最终享有组织收益分配权。 |
| 最终表决权关系 | 表决权自然人→自然人；目标组织→组织主体 | 自然人在特定期间最终享有组织表决权。 |
| 权利或控制安排 | 实际权利或控制自然人→自然人；受影响组织→组织主体；名义自然人→自然人；名义组织→组织主体 | 代持、表决委托、一致行动或控制协议等可能改变表面权利归属或最终决定能力的业务安排。 |
| 实际控制关系 | 控制自然人→自然人；被控制组织→组织主体 | 自然人单独或联合对组织的人事、重大经营决策、财务或重要资产资金形成最终支配。 |
| 组织业务角色 | 角色自然人→自然人；角色所在组织→组织主体 | 自然人在特定期间对组织承担法定代表人、日常管理人、负责人、投资人、授权代表或业务负责人等角色。 |
| 总分隶属关系 | 分支机构→分支机构；所属组织→组织主体 | 分支机构在特定期间隶属于一个境内组织或外国公司。 |
| 分支业务角色 | 角色自然人→自然人；分支机构→分支机构 | 自然人在特定期间担任分支高级管理人员、法定代表人或负责人。 |
| 信托自然人当事人角色 | 自然人当事人→自然人；信托→信托 | 自然人在信托中担任委托人、受托人、受益人或监察人。 |
| 信托非自然人当事人角色 | 非自然人当事人→组织主体；信托→信托 | 组织在信托中担任委托人、受托人、受益人或监察人，并需要继续识别实际控制信托的自然人。 |
| 信托受益范围 | 信托→信托；已指定自然人→自然人 | 受益人尚未具体确定时，信托可以存在可核实的受益范围；后续指定自然人时再形成具体人选。 |
| 信托最终控制权关系 | 控制自然人→自然人；信托→信托 | 自然人通过处分财产、决定投资分配、变更或终止信托、改变受益人资格或任免受托人等权能最终控制信托。 |
| 资管产品机构服务关系 | 服务机构→组织主体；资管产品→资产管理产品 | 组织对资产管理产品承担管理人、受托人、托管人等服务角色。 |
| 资管产品自然人管理角色 | 管理产品的自然人→自然人；资管产品→资产管理产品 | 自然人在特定期间实际承担管理产品的自然人角色。 |
| 自然人产品权利关系 | 自然人权利人→自然人；资管产品→资产管理产品 | 自然人在资管产品中享有可核实的份额、收益或表决等权利。 |
| 组织产品权利关系 | 组织权利人→组织主体；资管产品→资产管理产品 | 组织在资管产品中享有可核实的份额、收益或表决等权利，用于继续穿透最终自然人。 |
| 自然人产品控制关系 | 控制自然人→自然人；资管产品→资产管理产品 | 自然人对资管产品形成实际控制或关键决定权。 |

### 核心业务判断

| 业务判断 | 业务问题 | 判断方式 | 可能结果 |
| --- | --- | --- | --- |
| 自然人身份核实 | 候选人是否已经被可靠地核实为同一现实自然人？ | 专业判断 | 身份已核实、身份未核实、身份存在未知或冲突 |
| 名义与真实权利归属判断 | 登记名义人与最终权益、收益、表决或控制人不一致时，真实权利归谁？ | 专业判断 | 真实权利归属已证实、未形成权利转移、权利归属未知 |
| 最终权益标准判断 | 某自然人对目标组织的最终股权、股份或合伙权益是否达到25%（含本数）？ | 混合判断 | 满足标准一、不满足标准一、标准一未知 |
| 最终收益权或表决权标准判断 | 未按权益标准入选的自然人，最终收益权或表决权是否达到25%（含本数）？ | 混合判断 | 满足标准二、不满足标准二、标准二未知 |
| 实际控制标准判断 | 某自然人是否通过本人或联合机制最终实际支配目标组织？ | 专业判断 | 满足标准三、不满足标准三、实际控制未知 |
| 日常经营管理人备位判断 | 什么时候可以把实际负责日常经营管理的自然人作为备位受益所有人？ | 混合判断 | 备位人选成立、备位不适用、备位前提未知 |
| 国有独资、控股与参股分类 | 目标组织在判断时点属于国有独资、国有控股、仅国有参股还是无法确定？ | 专业判断 | 国有独资、国有控股、国有参股、非国资特例、国资性质未知 |
| 国资特殊识别人选判断 | 国有独资/控股组织在备案或金融机构识别语境下能否采用法定代表人路径？ | 混合判断 | 备案法定代表人路径成立、机构可采用法定代表人路径、按一般标准识别、特殊路径未知 |
| 分支机构受益所有人人选判断 | 境内分支和外国公司中国分支分别应识别哪些自然人？ | 专业判断 | 境内分支承继所属主体人选、外国分支双部分人选、分支人选未知 |
| 信托自然人识别判断 | 信托应识别哪些自然人受益所有人？ | 专业判断 | 信托自然人范围已完整识别、信托自然人范围部分确认、信托自然人范围未知 |
| 信托服务类别与简化资格判断 | 不同信托服务类别应采用完整识别还是可以简化？ | 混合判断 | 完整信托识别、可考虑简化、信托路径未知 |
| 资管产品一般识别判断 | 不适用特殊简化时，资管产品如何按真实所有权、收益、表决和控制结构识别自然人？ | 专业判断 | 产品一般识别人选完整、产品人选部分确认、产品一般识别未知 |
| 公开资管产品简化人选判断 | 公开募集/发行且满足管理受托、登记备案和托管条件的产品，简化后认定谁？ | 混合判断 | 简化认定管理产品自然人、回到一般产品识别、公开产品简化资格未知 |
| 其他低风险资管产品简化资格判断 | 其他金融机构管理/受托产品或低风险年金何时可简化？ | 专业判断 | 其他产品可考虑简化、按一般产品识别、简化资格未知 |
| 信托受托资料采信判断 | 其他金融机构何时可以采信受托信托公司提供的受益人资料？ | 专业判断 | 可以采信、要求重核或自行核实、采信结论未知 |
| 金融机构免识别资格判断 | 客户是否属于第十条可以免识别受益所有人的法定主体？ | 专业判断 | 可以免识别、不属于免识别类别、免识别资格未知 |
| 金融机构简化识别人选判断 | 第十一条各类主体在低风险等条件下简化识别时，最终应认定哪类自然人？ | 专业判断 | 专业服务机构负责人、合作经济组织法定代表人、个人独资企业投资人、合格境外投资者实际角色人选、外国企业常驻代表机构按分支路径、社会组织风险相称简化、国企专门路径、一般识别、简化资格或人选未知 |
| 风险对识别深度的影响判断 | 第二十条风险事实如何影响受益所有人识别深度和简化路径？ | 专业判断 | 维持一般识别、停止简化、加强识别、风险影响未知 |
| 权利、角色与控制有效期间判断 | 一项权利、安排、控制或角色在什么时间真正生效和终止？ | 专业判断 | 精确日期已证实、仅能确定时间区间、有效时间未知 |
| 受益所有权变化影响判断 | 客户存续期间的变化是否可能改变受益所有人人选、关系类型或有效时间？ | 专业判断 | 需要重新核实或更新、未发现影响受益所有权的实质变化、变化影响未知 |
| 历史时点受益所有权还原判断 | 历史业务发生时，当时哪些自然人拥有、受益、表决或控制目标主体？ | 专业判断 | 历史人选可确认、历史人选部分确认、历史归属未知 |
| 受益所有人结论形成与完整性判断 | 在当前责任语境和判断时点，哪些自然人可以作为已核实受益所有人，哪些必须保留未知？ | 专业判断 | 已形成完整可解释结论、已形成部分结论、无法形成确定结论 |

## 业务对象详解

### 自然人

能够以个人身份承担权益、控制或业务角色，并且只有自然人才可能成为最终受益所有人。

**如何识别同一业务对象：** 以可靠身份证明及签发法域核对同一现实自然人；姓名相同不能单独证明为同一人。

| 业务属性 | 类型 | 数量 | 业务含义 |
| --- | --- | --- | --- |
| 姓名 | Text | 1..1 | 经可靠来源核对的自然人姓名。 |
| 性别 | Text | 0..1 | 机构识别或备案要求下记录的自然人性别。 |
| 国籍 | Text | 0..1 | 自然人国籍。 |
| 出生日期 | Date | 0..1 | 自然人出生日期；透明客户特殊情形可仅取得法规允许的较少信息。 |
| 身份证明类别 | Text | 0..1 | 用于核实自然人身份的证件类别。 |
| 身份证明号码 | Text | 0..1 | 与签发法域共同支持身份同一性。 |
| 证件签发国家或地区 | Text | 0..1 | 身份证明签发国家或地区。 |
| 证件有效期限 | Date | 0..1 | 身份证明有效期限；过期不抹除历史身份。 |

**例子：** 甲以已核实身份持有目标公司权益。

**不能混同：** 不能把公司、信托或资管产品作为自然人受益所有人。

### 组织主体

公司、合伙企业、社会组织等具有独立组织身份、可承载权益和治理关系的非自然人主体。

**如何识别同一业务对象：** 优先以登记识别号、登记法域和连续登记材料识别同一组织；名称变化不当然产生新主体。

| 业务属性 | 类型 | 数量 | 业务含义 |
| --- | --- | --- | --- |
| 登记名称 | Text | 1..1 | 组织当前或历史登记名称。 |
| 登记识别号 | Text | 0..1 | 统一社会信用代码或同等登记标识。 |
| 登记法域 | Text | 1..1 | 组织登记或依法设立的法域。 |
| 组织形态 | Enum/COMPANY、PARTNERSHIP、SOLE_PROPRIETORSHIP、COOPERATIVE、PROFESSIONAL_SERVICE、SOCIAL_ORGANIZATION、QFII、FOREIGN_ENTERPRISE、PUBLIC_BODY、OTHER、UNKNOWN | 0..1 | 用于判断一般、特殊或豁免识别路径的法定组织形态。 |
| 设立日期 | Date | 0..1 | 组织设立或登记生效日期。 |

**例子：** A公司作为金融机构非自然人客户接受受益所有人识别。

**不能混同：** 组织名称中含“国有”或“协会”不能单独证明其适用特殊识别路径。

### 分支机构

依附于所属组织、但在特定规则下具有独立识别语义的境内分支或外国公司中国分支。

**如何识别同一业务对象：** 以分支登记标识、登记法域以及同一时点有效的总分关系共同识别。

| 业务属性 | 类型 | 数量 | 业务含义 |
| --- | --- | --- | --- |
| 分支登记名称 | Text | 1..1 | 分支机构登记名称。 |
| 分支登记识别号 | Text | 0..1 | 分支机构登记标识。 |
| 登记法域 | Text | 1..1 | 分支登记法域。 |
| 分支类型 | Enum/DOMESTIC_BRANCH、FOREIGN_COMPANY_CHINA_BRANCH、UNKNOWN | 1..1 | 区分境内组织分支与外国公司中国分支。 |
| 设立日期 | Date | 0..1 | 分支设立生效日期。 |

**例子：** 外国公司在中国设立的分支机构。

**不能混同：** 不能仅凭旧营业执照名称推断当前仍与原总公司存在有效总分关系。

### 信托

由委托人、受托人、受益人、监察人及其他最终控制权安排共同构成的信托关系对象。

**如何识别同一业务对象：** 以信托合同、登记或其他能够稳定区分具体信托的名称、编号和适用法域识别。

| 业务属性 | 类型 | 数量 | 业务含义 |
| --- | --- | --- | --- |
| 信托名称或编号 | Text | 1..1 | 合同、登记或其他正式材料中用于区分具体信托的名称或编号。 |
| 适用法域 | Text | 1..1 | 信托设立或适用的法域。 |
| 信托类别 | Enum/WEALTH_MANAGEMENT、CHARITABLE、CIVIL、FOREIGN、OTHER_ASSET_SERVICE、OTHER、UNKNOWN | 0..1 | 用于区分第十二、十三条下不同识别深度。 |
| 设立日期 | Date | 0..1 | 信托设立生效日期。 |

**例子：** 某财富管理服务信托按信托当事人和最终控制权识别自然人。

**不能混同：** 受托人名称不等于信托完整受益所有人名单。

### 资产管理产品

需要根据产品权利结构、管理受托关系、募集备案和风险判断受益所有人的资产管理产品。

**如何识别同一业务对象：** 以产品合同、产品名称或代码、依法登记备案信息共同区分具体产品。

| 业务属性 | 类型 | 数量 | 业务含义 |
| --- | --- | --- | --- |
| 产品名称或代码 | Text | 1..1 | 正式产品文件中用于稳定识别产品的名称或代码。 |
| 产品类别 | Enum/ASSET_MANAGEMENT_TRUST、ASSET_MANAGEMENT_PRODUCT、ENTERPRISE_ANNUITY、OCCUPATIONAL_ANNUITY、OTHER、UNKNOWN | 0..1 | 区分资产管理信托、企业年金、职业年金等产品类型。 |
| 募集方式 | Enum/PUBLIC、PRIVATE、OTHER、UNKNOWN | 0..1 | 产品公开或非公开募集/发行状态。 |
| 备案登记状态 | Enum/REGISTERED、NOT_REGISTERED、UNKNOWN | 0..1 | 产品依法备案或登记状态。 |

**例子：** 依法备案、由金融机构管理且本机构提供托管服务的公开募集产品。

**不能混同：** 仅有产品名称或单一备案编号不能自动证明满足简化识别全部条件。

### 识别证据

用于支持或质疑自然人身份、业务关系、角色、有效期间或业务判断的可追溯来源材料。

**如何识别同一业务对象：** 以来源记录标识与材料定位共同区分证据；同一文件不同条款可以分别定位。

| 业务属性 | 类型 | 数量 | 业务含义 |
| --- | --- | --- | --- |
| 来源标识 | Text | 1..1 | 原始文件、官方查询、客户材料或机构记录的可追溯标识。 |
| 材料位置 | Text | 1..1 | 页码、条款、登记记录或查询位置。 |
| 来源类型 | Enum/OFFICIAL_REGISTRY、CORPORATE_DOCUMENT、AGREEMENT、RESOLUTION、IDENTITY_DOCUMENT、TRUST_DOCUMENT、PRODUCT_DOCUMENT、INSTITUTION_RECORD、THIRD_PARTY、OTHER | 0..1 | 区分证据来源性质。 |
| 材料形成日期 | Date | 0..1 | 材料出具或形成日期，不自动等于权利生效日。 |
| 核实日期 | Date | 0..1 | 金融机构完成核实的日期。 |
| 可靠性状态 | Enum/VERIFIED、UNVERIFIED、CONFLICTED、UNKNOWN | 0..1 | 证据是否已核实、冲突或仍未知。 |
| 所支持或质疑的事实 | Text | 0..1 | 该证据具体支持或质疑的身份、权利、角色或时间事实。 |

**例子：** 生效的股权转让协议及其交割证明。

**不能混同：** 第三方图谱上的单一比例标签不能直接替代完整权利事实。

## 业务关系详解

### 自然人直接权益关系

自然人在特定期间直接持有组织的股权、股份或合伙权益。

| 参与角色 | 业务对象 | 数量 | 含义 |
| --- | --- | --- | --- |
| 自然人持有人 | 自然人 | 1..1 | 直接享有该段权益的自然人。 |
| 权益所及组织 | 组织主体 | 1..1 | 该段权益直接对应的组织。 |

**时间语义：** 每段关系按自身法律生效和终止时间有效；登记日与法律生效日分开。

**证据语义：** 股东名册、章程、合伙协议、转让协议及生效材料支持持有人、比例和期间。

**例子：** 甲自2026-01-01起直接持有A公司30%股权。

**不能混同：** 不能把甲控制B公司解释成甲直接持有B公司100%权益。

### 组织间权益关系

一个组织在特定期间直接持有另一个组织的股权、股份或合伙权益。

| 参与角色 | 业务对象 | 数量 | 含义 |
| --- | --- | --- | --- |
| 持有人组织 | 组织主体 | 1..1 | 权益链中的中间组织。 |
| 被持有组织 | 组织主体 | 1..1 | 权益链中的下一层组织。 |

**时间语义：** 每段组织权益关系独立保留有效区间，历史关系不得被当前结构覆盖。

**证据语义：** 登记、章程、合伙协议、转让及批准材料支持该段关系。

**例子：** B公司持有A公司60%，作为甲间接持股路径的一段。

**不能混同：** 不能把中间组织60%持股直接当成最终自然人60%。

### 最终收益权关系

自然人在特定期间最终享有组织收益分配权。

| 参与角色 | 业务对象 | 数量 | 含义 |
| --- | --- | --- | --- |
| 收益权自然人 | 自然人 | 1..1 | 最终享有收益权的自然人。 |
| 目标组织 | 组织主体 | 1..1 | 收益权所及组织。 |

**时间语义：** 收益权按安排真实生效和终止时间判断。

**证据语义：** 协议、章程、分配规则、持续履行记录及相关方确认共同支持收益权。

**例子：** 非登记股东甲依据有效协议享有A公司30%收益权。

**不能混同：** 单笔分红流水不能单独证明最终收益权达到30%。

### 最终表决权关系

自然人在特定期间最终享有组织表决权。

| 参与角色 | 业务对象 | 数量 | 含义 |
| --- | --- | --- | --- |
| 表决权自然人 | 自然人 | 1..1 | 最终享有或行使表决权的自然人。 |
| 目标组织 | 组织主体 | 1..1 | 表决权所及组织。 |

**时间语义：** 只在委托或其他安排有效期间计入。

**证据语义：** 生效的表决委托、章程、投票记录和相关确认支持表决权。

**例子：** 甲依据已生效委托享有A公司30%表决权。

**不能混同：** 未签署的委托草案不能形成有效表决权。

### 权利或控制安排

代持、表决委托、一致行动或控制协议等可能改变表面权利归属或最终决定能力的业务安排。

| 参与角色 | 业务对象 | 数量 | 含义 |
| --- | --- | --- | --- |
| 实际权利或控制自然人 | 自然人 | 1..* | 安排所赋予最终权利或控制能力的自然人；联合安排可有多人。 |
| 受影响组织 | 组织主体 | 1..1 | 安排所作用的目标组织。 |
| 名义自然人 | 自然人 | 0..1 | 代持等情形下的名义自然人；非代持可为空。 |
| 名义组织 | 组织主体 | 0..1 | 代持等情形下的名义组织；非代持可为空。 |

**时间语义：** 安排只在实际生效期间影响最终权利；终止或替换后不得继续沿用。

**证据语义：** 协议原件、履行事实、决议、投票和资金分配等共同支持安排效力。

**例子：** 乙依据生效代持协议成为A公司30%权益的实际权利人。；甲与乙依据一致行动协议共同决定A公司重大事项。

**不能混同：** 亲属关系、口头说法或单次签字本身不是已成立的代持或控制安排。

### 实际控制关系

自然人单独或联合对组织的人事、重大经营决策、财务或重要资产资金形成最终支配。

| 参与角色 | 业务对象 | 数量 | 含义 |
| --- | --- | --- | --- |
| 控制自然人 | 自然人 | 1..* | 经证实具有最终支配能力的自然人。 |
| 被控制组织 | 组织主体 | 1..1 | 实际控制所及组织。 |

**时间语义：** 实际控制形成、持续和终止按权限生效与持续行使事实确定，不以后来的标签倒推历史。

**证据语义：** 章程、协议、任免、董事会及重大决策记录、预算授权、账户或重要资产长期支配材料支持控制关系。

**例子：** 甲依据章程和持续决策事实最终决定A公司重大经营事项。

**不能混同：** 法定代表人、第一大股东、总经理或一次付款签名不能单独证明实际控制。

### 组织业务角色

自然人在特定期间对组织承担法定代表人、日常管理人、负责人、投资人、授权代表或业务负责人等角色。

**时间语义：** 角色按任命、授权或真实职责的生效和终止期间判断。

**证据语义：** 官方登记、任命、授权文件及实际职责材料支持角色。

**例子：** 甲在判断日为A公司的有效法定代表人。

**不能混同：** 登记法定代表人不自动等于实际控制人或日常管理人。

### 总分隶属关系

## 业务判断详解

### 自然人身份核实

**业务问题：** 候选人是否已经被可靠地核实为同一现实自然人？

将自然人身份与其权利是否成立分开判断；身份资料齐全不等于权利已经核实。

**判断输入：**
- 候选自然人的姓名、证件及签发法域。
- 官方身份查询、身份证明及补充材料。

**判断准则：**
- 优先采用可用官方渠道；不能使用官方渠道时，以有效身份证明及补充材料合理核实。
- 身份核实与权利核实分别作结论。

**单独不足以证明结论：**
- 同名字符串。
- 单独身份证复印件且与可得官方资料冲突。

**缺证/未知：** 身份资料冲突或关键身份证明缺失时维持 UNKNOWN，不把权利证据反推为身份已核实。

**需要的证据：**
- 官方身份查询结果。
- 有效身份证明及必要补充材料。

**人工边界：** 身份来源可靠性和冲突由金融机构有权核实人员负责；模型不定义内部岗位分工。

**结果落地语义：** 只有 VERIFIED 的自然人才能进入正式受益所有人结论；UNKNOWN 人选保持候选并列明补证。

### 名义与真实权利归属判断

**业务问题：** 登记名义人与最终权益、收益、表决或控制人不一致时，真实权利归谁？

根据代持、委托、一致行动或控制安排的效力和实际履行，确定表面登记背后的真实权利人。

**判断输入：**
- 影响权利归属或控制的安排。
- 协议原件、履行事实、分红、投票和相关方确认。

**判断准则：**
- 分别判断登记持有人、最终权益人、收益权人、表决权人和实际控制人。
- 代持或委托只有在效力及适用期间有证据时才改变表面归属。

**单独不足以证明结论：**
- 亲属关系。
- 口头说法。
- 单一工商登记比例。
- 只有一笔分红但不知道对应权利来源。

**缺证/未知：** 协议效力、权利范围或履行情况不清时，相关权利归属为 UNKNOWN。

**需要的证据：**
- 代持/委托/一致行动协议及生效条款。
- 持续履行、分红、投票、相关方确认和独立资料。

**人工边界：** 协议效力和证据冲突需要业务/法律审查；自动化不能仅凭亲属或登记标签确认。

**结果落地语义：** ATTRIBUTED 后，实际权利自然人进入对应权益、收益、表决或控制标准判断；UNKNOWN 不产生确定人选。

### 最终权益标准判断

**业务问题：** 某自然人对目标组织的最终股权、股份或合伙权益是否达到25%（含本数）？

对同一自然人、同一目标组织、同一判断时点的有效直接和间接权益路径进行计算和汇总。

**判断输入：**
- 被判断自然人。
- 目标组织。
- 自然人直接权益段。
- 中间组织权益段。
- 各段比例、持有人和有效期间证据。

**判断准则：**
- 每条有效无环路径按各段比例连乘。
- 同一自然人互不重合的有效路径贡献汇总。
- 最终比例达到或超过25%时满足标准一。
- 路径完整性必须先得到证据确认。

**单独不足以证明结论：**
- 第三方图谱单一比例。
- 中间公司控股即自然人100%持有。
- 未核实的上层路径按0计算。

**缺证/未知：** 任一可能影响结果的路径关键事实未知时，受影响的最终比例和标准一结果保持 UNKNOWN。

**需要的证据：**
- 逐层登记/章程/合伙协议。
- 各段转让、批准及生效材料。
- 能够证明路径完整性与去重的结构证据。

**人工边界：** 比例运算本身可确定计算；路径是否真实、完整、互不重合以及证据冲突需由有权人员核实。

**结果落地语义：** MATCHED 的已核实自然人按权益标准进入受益所有人结论；UNKNOWN 不能被当作未达到标准。

### 最终收益权或表决权标准判断

**业务问题：** 未按权益标准入选的自然人，最终收益权或表决权是否达到25%（含本数）？

收益权和表决权是两个独立判断维度，不与股权比例跨维度相加。

**判断输入：**
- 同一自然人的标准一结果。
- 最终收益权事实。
- 最终表决权事实。
- 协议、分配、投票及生效证据。

**判断准则：**
- 同一人已按标准一入选时不重复按标准二归类。
- 收益权和表决权分别核实，各自达到25%即可满足标准二。
- 收益权与表决权不能跨维度相加。

**单独不足以证明结论：**
- 单笔分红流水。
- 未签署的表决委托草案。
- 名义股权比例。

**缺证/未知：** 标准一 UNKNOWN 或收益/表决权存在可能改变结论的缺证时，标准二保持 UNKNOWN。

**需要的证据：**
- 收益分配协议及实际分配记录。
- 表决权委托、章程及投票记录。
- 权利生效和终止材料。

**人工边界：** 权利效力、重叠部分和真实履行需要人工核实；阈值判断本身可确定计算。

**结果落地语义：** MATCHED 的已核实自然人按收益/表决标准进入受益所有人结论；同一人同时满足实际控制可分别记录关系而不重复计人。

### 实际控制标准判断

**业务问题：** 某自然人是否通过本人或联合机制最终实际支配目标组织？

实际控制关注最终决定能力和实际作用，不以职位、股东排名或一次签字替代。

**判断输入：**
- 控制候选自然人。
- 目标组织。
- 已核实的实际控制关系事实。
- 控制协议、一致行动等安排。
- 权限及持续实际行使证据。

**判断准则：**
- 核实能否最终决定人事任免、重大经营管理决策、财务收支或长期支配重要资产/主要资金。
- 联合控制要分别说明每个自然人的权力和共同决策机制。
- 判断的是最终支配能力而非一次经办行为。

**单独不足以证明结论：**
- 第一大股东。
- 法定代表人、总经理或董事长职务。
- 朋友/亲属关系。
- 一次大额收付签名。
- 第三方“实控人”标签。

**缺证/未知：** 缺少有效协议、决议或持续履行事实时保持 UNKNOWN，不因未发现股权人便认定无控制。

**需要的证据：**
- 章程和控制协议。
- 任免、重大决策、预算和账户权限记录。
- 重要资产或资金长期支配事实。
- 联合行动及实际行使证据。

**人工边界：** 实际控制是证据权衡和业务/法律判断；自动化只能组织事实和线索。

**结果落地语义：** MATCHED 的已核实自然人按实际控制标准进入受益所有人结论。

### 日常经营管理人备位判断

**业务问题：** 什么时候可以把实际负责日常经营管理的自然人作为备位受益所有人？

备位只在权益、收益/表决和实际控制三项一般标准对组织整体均被充分证否后启用。

**判断输入：**
- 全部自然人权益标准是否均明确不成立。
- 全部自然人收益/表决标准是否均明确不成立。
- 全部自然人实际控制标准是否均明确不成立。
- 真实日常经营管理角色。
- 候选全集与管理职责证据。

**判断准则：**
- 必须先对组织整体完成前三项标准的候选与路径核查。
- 任一 UNKNOWN 阻断备位。
- 备位人选按真实日常经营管理职责认定，不按固定职务顺序替代。

**单独不足以证明结论：**
- 未检索到≥25%工商持股。
- 登记法定代表人或董事长头衔。

**缺证/未知：** 候选全集、任一路径或真实日常管理职责未知时，备位结果保持 UNKNOWN。

**需要的证据：**
- 完整上层权益、收益/表决和控制核查材料。
- 实际日常经营职责、任命和履职证据。

**人工边界：** 候选是否穷尽以及谁真正负责日常经营管理需要人工核实；不得自动回填法定代表人。

**结果落地语义：** MATCHED 的自然人以备位标准进入受益所有人结论；前三项任一 UNKNOWN 时不产生备位人选。

### 国有独资、控股与参股分类

**业务问题：** 目标组织在判断时点属于国有独资、国有控股、仅国有参股还是无法确定？

国资性质必须基于有效产权、表决、章程、协议和实际支配证据，不直接沿用其他监管语境标签。

**判断输入：**
- 目标组织。
- 逐层国有资本权益关系。
- 章程、协议和其他控制安排。
- 官方产权及控制证据。

**判断准则：**
- 区分国有独资/控股与仅参股。
- 第32号令国有实际控制企业标签不能自动等同备案或机构规则中的国有独资/控股。

**单独不足以证明结论：**
- 企业名称含“国”。
- 国有出资为第一大股东。
- 第三方“国资实际控制”标签。

**缺证/未知：** 缺官方产权链或相对控股决定权证据时返回 UNKNOWN。

**需要的证据：**
- 官方产权登记和逐层出资。
- 章程、表决安排、协议及实际支配材料。

**人工边界：** 国有控股与参股边界存在规则适用和证据判断，争议情形需国资/法规专业人员确认。

**结果落地语义：** 该分类只决定后续是否可以进入国资特殊识别路径；UNKNOWN 时不得先把法定代表人当受益所有人。

### 国资特殊识别人选判断

**业务问题：** 国有独资/控股组织在备案或金融机构识别语境下能否采用法定代表人路径？

备案“应当视同”和金融机构“可以认定”是两个不同责任语境。

**判断输入：**
- 国资性质分类。
- 判断时点有效的法定代表人角色。
- 本次是备案还是金融机构识别。
- 金融机构识别下的风险结论。

**判断准则：**
- 先确认国资性质和法定代表人任职。
- 备案国有独资/控股与金融机构简化分别判断。
- 仅国有参股时继续识别社会资本和非股权控制，国有资本部分可不再穿透。

**单独不足以证明结论：**
- 国资交易语境的实际控制企业标签。
- 国有参股事实。

**缺证/未知：** 任一关键资格未知时不产生确定法代人选，仍完成可证实的一般路径。

**需要的证据：**
- 国资产权及控制材料。
- 法定代表人任职证据。
- 金融机构风险判断。

**人工边界：** 国资边界和机构是否采用可选路径由有权人员判断；供应商标签不能自动触发。

**结果落地语义：** FILING_LEGAL_REP 或 INSTITUTION_LEGAL_REP_ALLOWED 只指向判断时点有效的自然人法定代表人；GENERAL_IDENTIFICATION 不产生特殊人选。

### 分支机构受益所有人人选判断

**业务问题：** 境内分支和外国公司中国分支分别应识别哪些自然人？

分支识别首先依赖同一时点有效的总分关系，再按分支类型形成不同人选组合。

**判断输入：**
- 目标分支。
- 同一时点有效总分关系。
- 分支高级管理人员等角色。
- 所属组织已经形成的合格自然人结论。
- 总分、总部结构及任职材料。

**判断准则：**
- 境内分支先确认所属主体并核既有尽调仍符合现行要求。
- 外国公司分支同时识别所属外国公司自然人和至少一名本分支高级管理人员。
- 总公司注销、恢复或关系断裂时逐段按历史事实判断。

**单独不足以证明结论：**
- 旧总公司名称或登记号。
- 分支独立营业执照。
- 外国母公司本国申报豁免。

**缺证/未知：** 总分链断裂时总部人选部分 UNKNOWN；可独立核实分支高管，但不能用其自动替代总部人选。

**需要的证据：**
- 当前/历史总分登记、注销恢复文件。
- 总部章程、股权控制材料和既有尽调。
- 外国分支高管任命和履职材料。

**人工边界：** 异常总分状态、境外材料真实性和资料复用由有权人员核实。

**结果落地语义：** DOMESTIC_INHERIT_PARENT 形成与所属主体相同的已核实自然人集合；FOREIGN_PARENT_PLUS_SENIOR 在所属外国公司合格自然人集合之外，至少增加一名判断时点有效的分支高级管理自然人。

### 信托自然人识别判断

**业务问题：** 信托应识别哪些自然人受益所有人？

信托识别覆盖自然人当事人、非自然人当事人的最终控制自然人以及其他对信托具有最终有效控制权的自然人。

**判断输入：**
- 被识别信托。
- 自然人委托人、受托人、受益人、监察人。
- 非自然人信托当事人。
- 未指定或已指定受益范围。
- 其他最终有效控制权。
- 合同、修订、当事人链和实际权能证据。

**判断准则：**
- 逐一确认委托人、受托人、受益人、监察人（如有）。
- 非自然人当事人继续识别最终有效控制信托的自然人。
- 另识别可处分财产、决定投资分配、变更终止信托、改变受益人或受托人的其他自然人。
- 未具体指定受益人时只记录受益范围，不编造姓名。

**单独不足以证明结论：**
- 只有受托人名称。
- 只有最终收益名单。
- 受益人未指定便认定无人受益。

**缺证/未知：** 非自然人上层、控制权或具体受益人未证实时保留 PARTIAL/UNKNOWN，不虚构自然人。

**需要的证据：**
- 信托合同、修订和登记。
- 四类当事人名单及非自然人穿透材料。
- 财产处分、投资分配、受益人指定和受托人更替记录。

**人工边界：** 信托财产权和指定权效力需要业务/法律审查；自动穿透不能替代最终控制判断。

**结果落地语义：** COMPLETE/PARTIAL 中已核实的自然人当事人、非自然人当事人的最终控制自然人及其他最终控制自然人构成信托受益所有人人选；未指定受益范围只保留范围，不生成确定自然人。

### 信托服务类别与简化资格判断

**业务问题：** 不同信托服务类别应采用完整识别还是可以简化？

财富管理、公益慈善、民事和外国信托按完整信托识别；其他资产服务信托只有结构简单且低风险时才具有简化资格。

**判断输入：**
- 信托服务类别。
- 完整信托自然人识别结果。
- 洗钱恐怖融资风险结论。
- 信托合同、结构和风险证据。

**判断准则：**
- 先确认信托类别。
- 前四类进入完整第十二条识别。
- 其他资产服务信托只有结构简单且风险较低两个条件同时成立时才可简化。

**单独不足以证明结论：**
- 产品名称写“信托”。
- 受托人自报低风险。

**缺证/未知：** 信托类别、结构或风险任一未知时不得使用简化，先维持完整识别。

**需要的证据：**
- 信托合同与服务类型证明。
- 结构图、当事人资料和风险评级依据。

**人工边界：** 信托类别和简化条件由有权尽调/风险人员确认。

**结果落地语义：** FULL_TRUST_IDENTIFICATION 继续使用 TrustIdentification 的自然人人选语义；当前固定知识只明确其他资产服务信托“可以简化”，未给出统一的简化后替代自然人人选，因此 SIMPLIFICATION_ELIGIBLE 本身不得直接生成具体受益所有人。

### 资管产品一般识别判断

**业务问题：** 不适用特殊简化时，资管产品如何按真实所有权、收益、表决和控制结构识别自然人？

以产品持有人和控制事实为基础，参照一般自然人受益所有人标准形成产品人选。

**判断输入：**
- 目标资管产品。
- 自然人产品权利。
- 非自然人产品权利及后续穿透。
- 自然人对产品的控制关系。
- 产品合同、持有人和控制材料。

**判断准则：**
- 按产品真实所有权、收益、表决和控制结构识别自然人。
- 组织持有人继续追溯最终自然人，不能把组织比例直接归给个人。

**单独不足以证明结论：**
- 产品名称。
- 单一备案编号。
- 管理公司本身。

**缺证/未知：** 关键持有人、比例或控制关系缺证时维持 PARTIAL/UNKNOWN。

**需要的证据：**
- 产品合同说明书。
- 持有人名册、收益和表决安排。
- 最终控制材料。

**人工边界：** 非自然人穿透和产品控制事实由有权人员核实。

**结果落地语义：** 已核实满足产品实际所有权、收益、表决或控制标准的自然人构成一般识别人选。

### 公开资管产品简化人选判断

**业务问题：** 公开募集/发行且满足管理受托、登记备案和托管条件的产品，简化后认定谁？

公开产品简化不是仅凭备案状态；四类条件均成立时，可以认定实际管理该产品的自然人为受益所有人。

**判断输入：**
- 目标产品的募集和登记状态。
- 金融机构管理/受托及本机构托管服务。
- 实际管理产品的自然人。
- 风险结论。
- 产品、服务和人选证据。

**判断准则：**
- 同时验证金融机构管理/受托、公开募集或发行、依法备案/登记、本机构提供托管等服务。
- 简化结果的人选必须是已核实的“管理产品的自然人”，不能用管理公司替代。

**单独不足以证明结论：**
- “公开产品”名称。
- 单一备案编号。
- 代销服务。

**缺证/未知：** 任何资格或自然人管理角色未知时不产生简化人选，先按一般产品识别补证。

**需要的证据：**
- 产品合同与说明书。
- 管理/受托机构资格。
- 募集备案凭证。
- 托管服务合同。
- 自然人实际管理职责证据。

**人工边界：** 产品形态、服务角色和风险由有权人员核实；供应商产品分类不能自动放行。

**结果落地语义：** SIMPLIFIED_TO_MANAGER_PERSON 时，将判断时点有效的 UBO.Rel.ProductPersonRole 中 role_type=NATURAL_PERSON_MANAGING_PRODUCT 的已核实自然人作为受益所有人人选；其余结果不产生该特殊人选。

### 其他低风险资管产品简化资格判断

**业务问题：** 其他金融机构管理/受托产品或低风险年金何时可简化？

其他产品需先充分评估风险；企业/职业年金等低风险产品可以简化，但固定知识没有给出统一的简化后自然人人选。

**判断输入：**
- 目标产品类别。
- 管理/受托及托管等服务关系。
- 机构风险评估。
- 产品和风险证据。

**判断准则：**
- 其他金融机构管理/受托产品由提供托管等服务机构充分评估风险。
- 企业或职业年金等低风险产品可以简化。

**单独不足以证明结论：**
- 只因名称含“年金”。
- 供应商标注低风险。

**缺证/未知：** 类别、服务关系或风险事实未知时不使用简化。

**需要的证据：**
- 产品合同和服务关系。
- 产品类别材料。
- 机构风险评估记录。

**人工边界：** 是否满足低风险简化由有权尽调/风险人员判断。

**结果落地语义：** 当前固定知识支持“可以简化”的资格判断，但没有给出所有此类产品统一的简化后自然人人选；SIMPLIFICATION_ELIGIBLE 不得被下游擅自转换成固定人选。

### 信托受托资料采信判断

**业务问题：** 其他金融机构何时可以采信受托信托公司提供的受益人资料？

采信资格与材料本身质量分别判断；合作关系不能自动免除本机构责任。

**判断输入：**
- 受托机构提供的受益人资料及权利材料。
- 受托机构AML体系及实际履责有效性。
- 资料是否有明显疑点或瑕疵。

**判断准则：**
- 先确认合作角色是否属于可采信范围。
- 再判断受托机构AML体系和履责是否有效。
- 明显疑点不能直接采信，可要求重核或自行核实。

**单独不足以证明结论：**
- 受托人为金融机构。
- 合作多年。
- 仅提供一份名单。

**缺证/未知：** 体系可靠性或明显疑点未澄清时为 UNKNOWN。

**需要的证据：**
- 信托受益人清单和权利材料。
- 合作/托管合同。
- 受托人体系评估、履责证明和疑点处理记录。

**人工边界：** 是否采信、要求重核及后续风险措施由本机构有权人员承担。

**结果落地语义：** RELY 只表示该资料可以作为识别证据使用，不把对方名单直接转换成本机构已确认受益所有人结论。

### 金融机构免识别资格判断

**业务问题：** 客户是否属于第十条可以免识别受益所有人的法定主体？

免识别必须基于官方设立和法定类别，不得由名称类比扩大。

**判断输入：**
- 客户组织形态和官方设立事实。
- 法定主体类别证据。

**判断准则：**
- 以官方登记/设立依据匹配机关法人及派出机构、事业单位、基层自治组织、农村集体、政府间国际组织、外国政府及其驻华机构等法定类别。

**单独不足以证明结论：**
- 名称含“政府”“事业”“协会”等。

**缺证/未知：** 主体法定类别不能准确判断时不得采用免识别。

**需要的证据：**
- 官方设立、登记及组织身份材料。

**人工边界：** 法定类别适用由机构有权人员依据正式材料核实。

**结果落地语义：** EXEMPT 表示当前金融机构无需按本规则识别受益所有人，因此不生成受益所有人人选；NOT_EXEMPT/UNKNOWN 继续其他识别路径。

### 金融机构简化识别人选判断

**业务问题：** 第十一条各类主体在低风险等条件下简化识别时，最终应认定哪类自然人？

不同主体类别只能使用自身规则允许的人选，且简化资格受风险闸门约束。

**判断输入：**
- 客户组织形态。
- 负责人、法定代表人、投资人、授权代表或业务负责人等真实角色。
- 外国企业常驻代表机构等分支对象。
- 外国代表机构需先参考外国分支规则。
- 国企另走专门法代路径。
- 风险闸门。
- 主体类别、角色和风险材料。

**判断准则：**
- 各主体类别的人选不能横向挪用。
- 类别和相应人选角色成立后，还须满足无较高风险或风险相称条件。
- 出现第二十条特定风险时停止简化/免识别并回一般或加强识别。

**单独不足以证明结论：**
- 客户自报低风险。
- 供应商预分类。
- 名称含“协会”“国企”。

**缺证/未知：** 组织性质、候选角色或风险闸门未知时不采用简化。

**需要的证据：**
- 主体设立登记材料。
- 负责人/投资人/法定代表人/授权代表/业务负责人角色证据。
- 风险评估记录。

**人工边界：** 风险相称性及可选简化由机构有权人员判断；社会组织没有统一固定人选时不得自动指定。

**结果落地语义：** 各明确人选型结果只把对应已核实自然人角色纳入受益所有人人选；SOCIAL_ORG_RISK_BASED 明确表示不存在本知识支持的统一固定人选，不得擅自套用其他类别人员；FOREIGN_REP_BRANCH_RULE 使用 BranchIdentification 的双部分人选语义。

### 风险对识别深度的影响判断

**业务问题：** 第二十条风险事实如何影响受益所有人识别深度和简化路径？

AML风险是外部输入；本判断只确定是否停止简化、加强核实或维持一般识别，不把风险标签本身当受益所有人事实。

**判断输入：**
- 当前风险等级。
- 具体风险触发事实。
- 境外查询失败、代持、循环结构、异常变化等证据。

**判断准则：**
- 逐项定位高风险地区、境外不可核、循环交叉、代持、异常变化、重大差异或洗钱嫌疑等具体事实。
- 加强措施与具体缺口相称；10%只是可选加强示例，不改写普通25%标准。

**单独不足以证明结论：**
- 仅有境外股东。
- 软件标签“复杂”。
- 客户拒绝一次资料请求。

**缺证/未知：** 外部风险事实无法核实时保持 UNKNOWN，不自动当低风险，也不直接替机构作拒办结论。

**需要的证据：**
- 风险来源和机构风险评级。
- 境外查询失败记录、结构和代持材料、异常变化证据。

**人工边界：** 措施选择、风险接受和拒办属于机构风险治理责任；本领域只消费其结论并约束识别深度。

**结果落地语义：** STOP_SIMPLIFICATION/ENHANCED_IDENTIFICATION 改变识别深度或可用路径，但不会凭风险标签自动增加、删除任何自然人受益所有人。

### 权利、角色与控制有效期间判断

**业务问题：** 一项权利、安排、控制或角色在什么时间真正生效和终止？

法律关系生效时间与登记、披露、机构核实、备案日期分别记录；只知范围时保留时间精度。

**判断输入：**
- 自然人权益关系时间。
- 组织权益关系时间。
- 收益权时间。
- 表决权时间。
- 安排时间。
- 实际控制时间。
- 角色时间。
- 生效、终止和条件完成证据。

**判断准则：**
- 按原始文件生效条款和条件完成事实确定法律关系起止。
- 首次达到标准日与后续当前比例形成日分别保留。
- 持续未退出时后续增持不抹掉首次达标日；退出后重入形成新的有效区间。

**单独不足以证明结论：**
- 工商变更登记日。
- BOMIS备案日。
- 机构查询日。
- 最近一次增持日。

**缺证/未知：** 只知月份或区间时不得自动补月首/年初；关系存在可以部分确定但精确日期仍 UNKNOWN。

**需要的证据：**
- 转让/控制协议及交割、批准证明。
- 章程、决议、合伙协议。
- 历史比例和控制变化材料。

**人工边界：** 生效条件是否满足以及冲突文件解释需要人工/法律审查。

**结果落地语义：** PRECISE_DATE/BOUNDED_INTERVAL 作为所有受益所有人判断的有效时间基础；UNKNOWN 不允许系统伪造精确形成日。

### 受益所有权变化影响判断

**业务问题：** 客户存续期间的变化是否可能改变受益所有人人选、关系类型或有效时间？

持续关注按具体自然人、权利关系和期间比较，而不是只比较名单总人数。

**判断输入：**
- 前后自然人权益。
- 前后收益权。
- 前后表决权。
- 前后实际控制。
- 关键角色变化。
- 信托当事人变化。
- 信托受益范围变化。
- 变更协议、决议、任免及生效资料。

**判断准则：**
- 比较前后具体自然人、关系类型、比例/控制方式和有效期间。
- 同数换人仍属于需要逐人核查的变化。
- 一般人事变动只有影响受益所有权时才触发相关更新。

**单独不足以证明结论：**
- 受益所有人总数没变。
- 登记控股股东数量没变。
- 一次普通人事调动。

**缺证/未知：** 只有传闻或生效日不明时保持 UNKNOWN，不直接删除旧人或断言无需更新。

**需要的证据：**
- 旧新权利结构和历史识别结果。
- 转让、委托、任免、信托指定及生效材料。

**人工边界：** 变化实质性和更新必要性由持续尽调人员判断；自动人头数比对不能替代。

**结果落地语义：** REIDENTIFY_OR_UPDATE 触发对受影响自然人、关系和时间重新执行相应领域判断；它不直接创造新的受益所有人人选。

### 历史时点受益所有权还原判断

**业务问题：** 历史业务发生时，当时哪些自然人拥有、受益、表决或控制目标主体？

历史判断只使用业务时点当时有效且有证据的关系，不把当前名单倒填历史。

**判断输入：**
- 需要还原的历史业务时点。
- 历史有效权益。
- 历史中间权益。
- 历史收益权。
- 历史表决权。
- 历史实际控制。
- 同期权利和规则证据。

**判断准则：**
- 所有关系都按历史业务时点 as-of 过滤。
- 保留入选/退出区间与来源可靠性。
- 当前共同受益人只能形成风险线索，不推出过去由同一人负责或交易可疑。

**单独不足以证明结论：**
- 当前工商图。
- 当前共同受益人标签。

**缺证/未知：** 形成日期与历史业务时点无法对应时保持 UNKNOWN。

**需要的证据：**
- 历史业务时间。
- 同期权利生效/终止文书。
- 当时适用规则和客户档案。

**人工边界：** 历史材料解释和风险用途由有权人员判断；本领域不推定历史责任。

**结果落地语义：** CONFIRMED/PARTIAL 只形成该历史时点的受益所有权事实视图，不把当前人选追认到历史，也不自动产生可疑交易或责任结论。

### 受益所有人结论形成与完整性判断

**业务问题：** 在当前责任语境和判断时点，哪些自然人可以作为已核实受益所有人，哪些必须保留未知？

把各识别标准的人选、身份、权利、有效期间和证据合并为业务结论，同时显式保留缺证和冲突。

**判断输入：**
- 自然人身份核实结果。
- 权益标准结果。
- 收益/表决标准结果。
- 实际控制结果。
- 备位结果。
- 国资特殊路径。
- 分支人选。
- 信托人选。
- 公开产品特殊人选。
- 其他法定简化人选。
- 结论属于备案还是机构独立识别。
- 结论依据和冲突证据。

**判断准则：**
- 逐人注明满足的识别标准、比例或控制方式、权利路径和有效时间。
- 同一自然人满足多个标准时保留多项关系但不重复计人。
- 备案结论与金融机构独立识别结论分别形成，不能互相替代。
- UNKNOWN 不得并入 FALSE 或“已确认全量名单”。

**单独不足以证明结论：**
- 供应商只给一个姓名和比例。
- 备案已有姓名。
- 第三方计算结果。

**缺证/未知：** 任何可能改变最终人选的关键未知都必须在结论中保留并指出具体补件。

**需要的证据：**
- 逐人身份和权利原始文书。
- 独立核实记录。
- 权利形成终止证据。
- 必要的风险和特殊路径材料。

**人工边界：** 金融机构对其独立识别和风险使用负责；备案主体对备案负责；具体机构审批岗位由外部正式制度决定。

**结果落地语义：** CONFIRMED/PARTIAL 中只有身份已核实且对应标准成立的自然人作为已确认受益所有人人选；PARTIAL/UNKNOWN 同时携带明确未决关系和补证要求，不把候选或冲突人选伪装成已确认。
