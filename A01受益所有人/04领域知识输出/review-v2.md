<a id="section-concepts"></a>
## 关键概念与边界


<a id="K.T.13"></a>
### 简化识别


在主体类型和风险条件均满足时，金融机构减少识别核实复杂度的措施。

容易混淆的边界：不等于无需判断，也不等于自动采信BOMIS。

实例：经性质、适用性和风险评估后，金融机构按相应条款将法定代表人认定为受益所有人。

反例：只看到国资股东名称便直接通过，尚未满足简化的前提。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.14"></a>
### 风险门控


在采用简化措施前后，根据客户洗钱和恐怖融资风险决定是否允许、收紧或终止简化。

容易混淆的边界：不是单一风险评分阈值。

实例：性质已明确但发生无合理理由的异常变更，仍进入风险核实和对应加强处理。

反例：把未取得风险资料当成没有风险。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.15"></a>
### 国有实际控制企业


32号令第四条第（四）项所述，国有相关主体持股未超过50%但为第一大股东且能通过安排实际支配的企业。

容易混淆的边界：它提供企业性质认定依据，不直接等于12号令已允许简化。

实例：合资格国有主体持股40%、为第一大股东，并有经核实的实际支配安排。

反例：国有主体持股40%且第一大，但尚无实际支配安排的证据。

依据：[《企业国有资产交易监督管理办法》（国资委 财政部令第32号）.pdf](#SRC01)

<a id="K.T.16"></a>
### 国有相对控股


本任务采用的用户业务口径：在核实国有主体第一大股东地位及实际支配能力等条件后，对持股未超过50%的企业进一步作国有相对控股判断；不能仅凭国资比例或名称确定。

容易混淆的边界：需先证明企业性质，再判断12号令适用性和风险。

实例：依用户口径，在核实32号令第（四）项性质后，继续形成国有相对控股判断并核对12号令适用性。

反例：把国资参股或第一大股东标签本身当成相对控股认定完成。

依据：[《企业国有资产交易监督管理办法》（国资委 财政部令第32号）.pdf](#SRC01)；[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.17"></a>
### 国有参股公司


有国有资本参股但不满足国有独资或国有控股认定的公司。

容易混淆的边界：仅可在一般识别中不再识别国有资本部分，不能把全部主体简化为法定代表人。

实例：国资30%、自然人乙60%、丙10%，且国资不能实际支配企业。

反例：国有主体虽不超过50%，但符合第一大股东及实际支配等条件，不能只凭比例当成普通参股。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.18"></a>
### 形成日期


受益所有权法律关系实际生效的日期；按本任务用户已答口径，当前形成日期取最近一次连续达标区间的开始日期，并保留历史中断。

容易混淆的边界：不同于资料取得日、系统录入日或法定30日更新期限。

实例：先前资格已中断，2024年6月2日重新达标且持续至今，当前形成日期按用户口径取6月2日。

反例：以本次查询日覆盖仍连续有效的既有形成日期。

依据：[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="K.T.19"></a>
### 终止日期


某项受益所有权关系不再有效或不再满足标准的日期。

容易混淆的边界：历史终止不应被当前重新达标覆盖。

实例：有效关系变化导致原达标关系终止时，应保留该终止事件及证据以解释中断。

反例：未取到证据便自行指定终止日期，或将录入日视为终止日。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC03)

<a id="K.T.20"></a>
### 重大差异


足以影响受益所有人、关键身份或权利关系认定，或形成终止时间出现年月差异的核对差异。

容易混淆的边界：不同于拼写差异或不影响最终认定的比例、方式差异。

实例：形成日期从2022年3月变为4月，属于原文列举的年月差异分支。

反例：仅因两边存在任意文本差别就一律认定重大，未核对第二十九条例外。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.21"></a>
### 非重大差异


符合12号令第二十九条列明情形的差异，如同一人非汉字姓名的拼写差异、权利信息非重大不一致、金融机构更严格识别标准引起的不一致或其他不影响识别的差异。无需提交差异报告，仍应记录核实、不报告理由和措施并提示客户。

容易混淆的边界：不等于无需处理或无需提示客户。

实例：同一人的比例略有不同，但核实不影响关系类型认定，且无其他重大情形，适用相应非重大分支。

反例：有形成日期年月差异，却只因人员没变而称为非重大。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.22"></a>
### 时点性待更新


本轮建议用于标记真实近期变更已发生、备案主体尚在法定更新期且需持续跟踪的差异状态。

容易混淆的边界：它不是重大性豁免，也不是日期容差。

实例：实际变更10日后备案仍未更新，记录其尚处更新期并跟踪，同时继续核实差异性质。

反例：把相差29日直接当作无差异或法定豁免。

依据：用户口径或合成讨论材料，非制度原文

<a id="K.T.23"></a>
### 已解决差异


本轮建议用于标记客户已实际更正且机构通过系统复核确认一致的闭环状态。

容易混淆的边界：已提交、口头承诺或等待系统更新均不等于已解决。

实例：客户实际更正，且金融机构重新查询比对一致。

反例：只有更正申请或口头承诺，还未复核一致。

依据：用户口径或合成讨论材料，非制度原文

<a id="K.T.01"></a>
### 受益所有人


最终拥有或实际控制备案主体，或者享有备案主体最终收益的自然人。

容易混淆的边界：不是登记股东、法定代表人或系统返回人员的同义词；这些人员只有在适用规则下才成为受益所有人。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.02"></a>
### 备案主体


依法通过登记注册系统备案受益所有人信息的公司、合伙企业、外国公司分支机构及规定的其他主体。

容易混淆的边界：不同于承担客户尽职调查义务的金融机构。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC03)

<a id="K.T.03"></a>
### 最终拥有


自然人经直接或间接路径在实质上拥有股权、股份或合伙权益。

容易混淆的边界：不同于仅在某一中间层登记持有。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC03)

<a id="K.T.04"></a>
### 直接拥有


自然人直接作为备案主体股东或合伙人拥有相应权益。

容易混淆的边界：不包括经中间主体传递的权益。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC03)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="K.T.05"></a>
### 间接拥有


自然人通过一层或多层主体最终拥有目标主体权益。

容易混淆的边界：不能只看最近一层股东。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC03)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="K.T.06"></a>
### 收益权


从股权、股份或合伙权益取得分红、增值等收益的权利。

容易混淆的边界：不同于名义持股，也不同于仅有合同债权。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.07"></a>
### 表决权


对主体治理事项作出或影响表决的权利。

容易混淆的边界：与收益权可以分离，且不自动等同于实际控制。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.08"></a>
### 实际控制


自然人单独或联合对人事、重大经营管理、财务收支、重要资产或主要资金实施实质支配。

容易混淆的边界：职位、亲属关系或少量持股只是线索，需有控制事实。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[《企业国有资产交易监督管理办法》（国资委 财政部令第32号）.pdf](#SRC01)；[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.09"></a>
### 联合控制


自然人通过一致行动、协议或关系安排与他人共同形成实际支配。

容易混淆的边界：不同于多人各自独立持股。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.10"></a>
### 负责日常经营管理的人员


前三项标准均无人满足时用于兜底识别的最高层级日常经营管理人员。

容易混淆的边界：不能在未完成前三项识别时提前替代穿透。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC03)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="K.T.11"></a>
### 承诺免报


同时满足资本规模、自然人股东或合伙人及不存在股东外和股权外控制收益安排时，由备案主体承诺后免于备案。

容易混淆的边界：这是备案义务分支，不等于金融机构免于识别。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC03)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="K.T.12"></a>
### 免于识别


12号令对列明法人、非法人组织允许金融机构不识别其受益所有人的制度安排。

容易混淆的边界：不同于备案承诺免报，也不同于简化识别。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.24"></a>
### 佐证材料


用于理解和核实所有权、控制权、身份与权利状态的可靠材料、数据或信息。

容易混淆的边界：单一客户声明或单次系统返回不自动等于充分可靠。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.25"></a>
### 查询核对


金融机构将独立识别结果与BOMIS保存的备案信息进行逐项比较。

容易混淆的边界：不是从BOMIS直接取得结论。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="K.T.26"></a>
### BOMIS
