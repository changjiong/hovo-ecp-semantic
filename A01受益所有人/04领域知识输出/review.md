# 领域业务知识说明书：受益所有人识别与持续管理

版本 0.4.0，2026年9月11日。本轮评审方式：IN_SESSION；本轮业务答复已写入草案，因缺少具名确认人和角色，正式确认状态仍为待确认。

<a id="section-scope"></a>## 一、范围、证据层级与业务全貌

本说明书回答金融机构如何识别、核实和持续管理非自然人客户的受益所有人，以及如何处理备案信息和差异。它不下达平台、数据映射或运行结论。

**证据层级。** 第一层是第12号令、第3号令、第二版指南及第32号令相关条款，它们决定识别、备案、国企性质、时间、差异和风险的业务口径。地方指引仅补充办事说明；BOMIS接口规范只解释报文交互。第二层同业材料只用于高频情境、案例线索和冲突发现，不能补出制度没有规定的阈值、期限、例外或责任。文章与制度冲突时，记录冲突并返回规范原文，不采纳文章替代结论。

识别过程是：明确客户和风险，调查所有权、收益、表决和控制，核实身份与权利，形成机构判断；对适用客户查询备案信息并分析差异；更新当前结论、保留历史和跟踪处理。共同受益所有人只是关联分析线索，不自动证明违法或可疑。

<a id="section-concepts"></a>## 二、概念与边界

<a id="K.T01"></a>**受益所有人：** 最终拥有、实际控制客户或享有最终收益的自然人。 不等于法定代表人、直接股东或系统推荐的人名。

<a id="K.T02"></a>**最终拥有：** 通过直接或间接权益对目标客户拥有规定比例的自然人。 不将循环或重叠权益在缺证时算为零。

<a id="K.T03"></a>**实际控制：** 能通过安排实际决定人事、重大经营管理、财务或重要资产资金事项的事实。 亲属、职务或标签不是单独充分依据。

<a id="K.T04"></a>**权利关系形成时间：** 相应权利法律关系生效的时间。 不等于查询、登记、核实或备案提交时间。

<a id="K.T05"></a>**备案：** 市场主体向制度规定系统填报的行为或结果。 不是金融机构识别核实结论。

<a id="K.T06"></a>**识别核实：** 机构识别候选并以合理措施核验身份和权利的工作。 不是单次系统比对。

<a id="K.T07"></a>**承诺免报：** 备案制度中同时满足四项条件后的填报安排。 不等于免予识别或简化识别。

<a id="K.T08"></a>**重大差异：** 影响人员、关键身份、关系类型或规定时间的差异。 不是任意字符串不一致。

<a id="K.T09"></a>**日常经营管理人员：** 在不存在三项识别情形时，实际负责日常经营的人员。 不能因穿透失败或只看法定代表人就兜底。

<a id="K.T10"></a>**证据不足：** 现有材料不足以支持某项判断。 不等于该权利或人员不存在。

<a id="section-cases"></a>## 四、案例

<a id="K.C01"></a>**甲30%、乙25%、丙25%收益、丁实际控制。** 预期：逐人应用相应标准，四人均可能入选。 禁止：不得只保留第一大股东。

<a id="K.C02"></a>**同一自然人两条无环路径均有证实比例。** 预期：按指南示例逐段相乘再相加。 禁止：不得推广为循环权益公式。

<a id="K.C03"></a>**持股5%但有有效协议控制重大事项。** 预期：进一步核实协议与实际控制后按控制标准判断。 禁止：不得仅因持股低排除。

<a id="K.C04"></a>**登记持有人与实际获益控制人不同，有代持文件。** 预期：分别核实两人的权利，再判断。 禁止：不得仅由亲属关系推定代持。

<a id="K.C05"></a>**国资30%、甲60%、乙10%。** 预期：不穿透相应国资部分，甲仍应按其权益判断。 禁止：不得因出现国资停止全部识别。

<a id="K.C06"></a>**2024年30%、2025年40%、2026年核实。** 预期：分别记录首次达标、当前权利生效和核实时点。 禁止：不得把三项时间合并。

<a id="K.C07"></a>**客户先更正，或已提交但系统未同步。** 预期：分别调查初始差异和真实备案提交事实。 禁止：不得一概以再次一致删除记录。

<a id="K.C08"></a>**境外法人股东无法提供最终自然人材料。** 预期：记录断点并加强核实或提交风险判断。 禁止：不得改填管理人员或把未知当零。

<a id="K.C09"></a>**收到报文接收应答，仍待审核。** 预期：按待审核跟踪直至办结或失败。 禁止：不得把发送写成办结。
