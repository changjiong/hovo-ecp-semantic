## 关键概念与边界


<a id="T01"></a>
### 受益所有人


最终拥有、控制或享有主体最终收益的自然人。

容易混淆的边界：不是法人、法定代表人或名义股东的同义词。

同义称呼：最终受益人

实例：持股30%的自然人可符合第一标准。

反例：仅任法定代表人但并无适用兜底或特例，不能当然入选。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[00业务问题.md](#SRC.TXT001)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)

<a id="T02"></a>
### 备案主体


按3号令承担受益所有人备案义务的主体。

容易混淆的边界：与12号令所称金融机构非自然人客户不是同一集合。

实例：公司A属于3号令的备案主体。

反例：个体工商户不在现行备案范围内。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)

<a id="T03"></a>
### 承诺免报


满足3号令第三条全部条件后，经承诺免于填报受益所有人信息。

容易混淆的边界：不同于金融机构免于识别客户受益所有人。

实例：自然人股东、出资额500万元且不存在额外控制获益安排的公司可经真实承诺申请免报。

反例：有外部代持受益人的公司不能仅凭注册资本较低而免报。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)

<a id="T04"></a>
### 最终拥有


自然人经直接或多层股权、股份、合伙权益路径最终拥有目标主体。

容易混淆的边界：不等于只看登记的直接股东。

实例：甲沿两层公司持股路径最终拥有A公司30%。

反例：只知道B公司直接持有A公司30%，尚未知道B公司背后的自然人。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)

<a id="T05"></a>
### 最终收益权


自然人最终享有股权或合伙权益收益的权利。

容易混淆的边界：可与名义股权分离；一般经营收入不是当然的股权收益权。

实例：丙不持股，但依据有效协议享有A公司30%股权的分红收益。

反例：丙从A公司取得劳务报酬，不因此拥有30%股权收益权。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)

<a id="T06"></a>
### 表决权


对主体决议表达意见并形成表决结果的权利。

容易混淆的边界：可经协议与名义股权分离，须核对实际享有比例。

实例：丙经股东协议实际享有A公司51%表决权。

反例：丙只是列席会议，无表决权或代理授权。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)

<a id="T07"></a>
### 实际控制


自然人单独或联合对人事、重大经营、财务或重要资产形成实质支配。

容易混淆的边界：亲属、创始人或普通合伙人身份本身不等于已证明控制。

实例：甲持股5%，依一致行动协议实际决定董事任免。

反例：甲与大股东是亲属，但没有可证实的共同决策或支配事实。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)

<a id="T08"></a>
### 日常经营管理兜底


三项一般标准均找不到自然人时，对负责日常经营管理人员的替代识别。

容易混淆的边界：是最后顺位，不得覆盖已经找到的受益所有人。

实例：三标准均经核对无人满足后，确认最高层级日常经营管理人员。

反例：已有持股30%的自然人，却仅填法定代表人。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)；[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T09"></a>
### 权利路径


从目标主体沿股权、协议、收益或控制关系到最终自然人的可说明链条。

容易混淆的边界：数值路径与实际控制事实可能并行，不能仅以乘积覆盖协议控制。

实例：丙经B和C两条持股路径分别取得14%和17.5%，合计31.5%。

反例：只有工商直接股东名单而没有上层股权链。

依据：[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)；[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T10"></a>
### 国有资本部分


在国有参股主体中可不继续向自然人追溯的国有出资部分。

容易混淆的边界：不能把整个国有参股公司免于识别。

实例：国有资本持有参股公司30%，其余自然人股权仍逐项识别。

反例：把国有参股公司整体视作无须识别受益所有人。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)；[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T11"></a>
### 信托当事人


信托委托人、受托人、受益人以及监察人如有。

容易混淆的边界：其他最终有效控制者不因未列为信托当事人而被排除。

实例：信托合同列明委托人、受托人、受益人与监察人。

反例：只登记受托人，遗漏拥有分配方案决定权的其他自然人。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T12"></a>
### 管理产品的自然人


在满足特定资管产品简化条件时可被认定的管理该产品的人。

容易混淆的边界：不是所有资管产品一概取管理人法定代表人。

实例：符合12号令第十四条条件的公募登记产品，在托管服务中认定具体管理产品的自然人。

反例：仅因产品名称含‘基金’就直接认定管理人法定代表人。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T13"></a>
### 佐证材料


用于证明自然人身份、权利关系、结构和生效时间的可靠材料、数据或信息。

容易混淆的边界：客户自报、BOMIS数据和自动化结果各有证明边界。

实例：生效的股权转让协议配合章程、登记及身份资料说明路径和日期。

反例：单个商业数据库搜索结果而无独立核验。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T14"></a>
### 受益所有权关系形成时间


最终拥有、实际控制或享有最终收益的法律关系生效时间。

容易混淆的边界：不同于工商登记日、查询日及机构核实日。

实例：股权转让协议约定并实际于6月1日生效。

反例：机构9月1日查询到该股权就把9月1日写为形成日。

依据：[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)；[00业务问题.md](#SRC.TXT001)；[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T15"></a>
### 权利终止时间


具体受益所有权关系停止存在的时间，如有。

容易混淆的边界：受益所有人名单变动不自动说明旧关系的终止日。

实例：控制协议明确于8月31日终止并有后续执行证据。

反例：某人不在今天名单上就推定其去年已经终止控制。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)；[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)；[00业务问题.md](#SRC.TXT001)

<a id="T16"></a>
### 基于风险的识别


按客户组织形式、洗钱及恐怖融资风险配置识别与核实强度。

容易混淆的边界：不能以低风险为由省略必须识别的自然人。

实例：复杂代持客户增加独立资料和回访。

反例：不区分风险，对全部客户一律收取所有可能材料。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T17"></a>
### 加强识别


出现特定风险后采用匹配风险的额外核实、监测、阈值或批准措施。

容易混淆的边界：10%阈值只是可选加强措施，不是通用门槛。

实例：重大差异后补充独立证据、提高更新频率。

反例：把10%作为所有普通客户的统一法定阈值。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T18"></a>
### 简化识别


在列明主体、产品及风险条件下适用较简方式的识别。

容易混淆的边界：与无条件豁免、备案承诺免报均不同。

实例：经充分风险评估的国有控股公司，按12号令第十一条采用相应简化措施。

反例：因为企业名称含‘国资’就不调查其控制结构。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T19"></a>
### BOMIS备案信息


受益所有人信息查询管理系统保存的备案结果。

容易混淆的边界：它是核对对象，不自动替代机构自己的识别结论。

实例：机构查询到客户备案的甲并与自身识别结果核对。

反例：BOMIS显示甲就不再核实甲的权利状况。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)；[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC.SRC01)；[受益所有人信息查询管理系统接口报文规范-V2.0.docx](#SRC.SRC07)

<a id="T20"></a>
### 重大差异


足以影响受益所有人或关键身份、权利类型及重要时间认定的备案与识别差异。

容易混淆的边界：非每个数值、拼写差异都属于重大差异。

实例：备案遗漏一名已证实的受益所有人。

反例：同一人的非汉字姓名仅有缩写差异。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T21"></a>
### 非重大差异


不影响最终识别等、按12号令第二十九条无须提交差异报告的差异。

容易混淆的边界：仍须记录分析、不报原因并提示客户。

实例：已证实同一人英文名缩写不同，仍按规定记录并提示。

反例：备案少了一名真正的受益所有人。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)；[受益所有人信息查询管理系统接口报文规范-V2.0.docx](#SRC.SRC07)

<a id="T22"></a>
### 差异报告


在规定情形下经查询、沟通、核实后向BOMIS提交的差异反馈。

容易混淆的边界：不同于可疑交易报告或接口受理回执。

实例：有充分证据证明备案遗漏受益所有人，经沟通核实后提交重大差异报告。

反例：接口同步受理回执不是报告最终办结。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)；[受益所有人信息查询管理系统接口报文规范-V2.0.docx](#SRC.SRC07)

<a id="T23"></a>
### 持续审核更新


业务关系存续期间出现可能影响受益所有权变化时再审并必要时更新。

容易混淆的边界：不是开户时识别一次后永久有效。

实例：控制协议重大变更后重新审核实际控制人。

反例：开户时名单未经复核就永久沿用。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC.SRC02)

<a id="T24"></a>
### 业务时点的权利状态


某项交易或尽调时间点上实际生效的拥有、控制和收益关系。

容易混淆的边界：不能直接用今天的名单回填历史。

实例：追查2024年交易时，使用当时已生效且尚未终止的股权关系。

反例：拿2026年当前股东直接认定其控制2024年交易。

依据：[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)；[00业务问题.md](#SRC.TXT001)

<a id="T25"></a>
### 推荐标识


同业产品在完整识别结果之外提供的优先展示或关系类型标注。

容易混淆的边界：推荐不缩减依法应识别的全部自然人，也不是监管裁定。

实例：甲乙丙分别符合三标准，界面优先显示甲但仍保留乙丙。

反例：只显示推荐的一人并删除其他符合者。

依据：[20260717_企查查新受益所有人：推荐规则解析与法规依据解读.md](#SRC.TXT063)；[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)

案例用于验证规则边界，不承担枚举完整领域的职责。优先审阅来源案例和经业务确认的真实案例；合成案例只用于探测反例、边界和缺证行为，不能反向证明本次生成规则正确。全部案例记录见 [审计附件](coverage.md#section-cases)。

<a id="C01"></a>
#### 案例 01｜A公司自然人甲55%、乙20%、丙25%。（C01）


用于回答：[哪些自然人经直接或间接路径最终拥有至少25%的股权或合伙权益？](#Q03)

案例性质：来源材料案例。

- A公司自然人甲55%、乙20%、丙25%。



判断过程：按每人最终股权比较含本数的25%门槛。

预期结果：甲与丙符合第一标准；25%含本数。

不得得出：把丙排除或把乙纳入。

依据：[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)



<a id="C02"></a>
#### 案例 02｜A公司甲直接30%；丙沿两条路径合计31.5%，乙21%，丁17.5%。（C02）


用于回答：[哪些自然人经直接或间接路径最终拥有至少25%的股权或合伙权益？](#Q03)

案例性质：来源材料案例。

- A公司甲直接30%；丙沿两条路径合计31.5%，乙21%，丁17.5%。



判断过程：逐路径乘积并按同一自然人汇总，最终股权达到25%者入选。

预期结果：甲和丙符合第一标准。

不得得出：只计算丙的一条路径或把乙纳入。

依据：[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)



<a id="C03"></a>
#### 案例 03｜甲、乙各持股30%、70%；甲将其30%股权的收益权转让给不持股的丙，仍保留投票权。（C03）


用于回答：[未满足第一标准的人是否最终享有至少25%的收益权或表决权？](#Q04)

案例性质：来源材料案例。

- 甲、乙各持股30%、70%；甲将其30%股权的收益权转让给不持股的丙，仍保留投票权。



判断过程：名义及最终股权、收益权分开判断。

预期结果：甲乙按股权第一标准、丙按收益第二标准识别。

不得得出：因甲转让收益权就删除其股权标准结论。

依据：[受益所有人信息备案指南（第二版）.pdf](#SRC.SRC06)



<a id="C04"></a>
#### 案例 04｜甲仅持股10%，另经协议获得20%股权所附收益权，合计收益权30%。（C04）
