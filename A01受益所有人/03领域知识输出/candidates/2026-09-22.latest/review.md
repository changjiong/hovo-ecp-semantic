## 关键概念与边界


<a id="TERM.BENEFICIAL_OWNER"></a>
### 受益所有人


符合至少一条法定识别路径的自然人；备案和金融机构客户识别分别有对应适用范围。

容易混淆的边界：受益所有人不是系统返回结果的同义词；查询、备案和金融机构识别是不同环节。

同义称呼：最终受益人

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="TERM.OWNERSHIP_PATH"></a>
### 股权/股份/合伙权益路径


自然人直接或间接最终拥有主体25%以上股权、股份或合伙权益的识别路径。

容易混淆的边界：直接登记比例与最终穿透比例不是同一事实。

同义称呼：标准一

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="TERM.BENEFIT_RIGHT"></a>
### 收益权


取得股权或合伙权益收益的权利，包括分红、权益增值等典型收益。

容易混淆的边界：收益权可与登记股权分离，不能用登记持股替代。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="TERM.VOTING_RIGHT"></a>
### 表决权


对主体决策表达和形成表决结果的权利，可因协议等安排与股权分离。

容易混淆的边界：表决权比例和股权比例需要分别取证。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="TERM.ACTUAL_CONTROL"></a>
### 实际控制


单独或联合决定人事、重大经营管理、财务收支或长期支配重要资产和主要资金等控制事实。

容易混淆的边界：法定代表人身份本身不等于实际控制证据。

同义称呼：标准三

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="TERM.FALLBACK_MANAGER"></a>
### 日常经营管理人员兜底


三条识别标准均不能确认自然人时，才使用日常经营管理人员作为兜底识别对象。

容易混淆的边界：缺少股权或控制证据不能直接触发兜底。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="TERM.TRUST_PARTY"></a>
### 信托当事人


委托人、受托人、受益人、监察人（如有）及最终有效控制自然人构成信托识别范围。

容易混淆的边界：信托不能套用普通公司股东路径。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="TERM.SIMPLIFIED"></a>
### 简化识别


在风险充分评估且满足特定主体或产品条件时采取的与风险匹配的较简识别措施。

容易混淆的边界：简化不是免除识别，也不是自动选项。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="TERM.EXEMPTION"></a>
### 承诺免报/豁免


在规定条件全部满足且无相反高风险事实时，允许不另行备案或免除特定识别步骤的制度安排。

容易混淆的边界：豁免条件无法准确判断时不得适用。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[受益所有人信息备案指南（第二版）.pdf](#SRC05)；[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="TERM.FORMATION_DATE"></a>
### 受益所有权关系形成日期


拥有、控制或最终获益法律关系实际生效的日期。

容易混淆的边界：查询日期、备案日期和形成日期不能混用。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行国家市场监督管理总局令〔2024〕第3号（受益所有人信息管理办法）.pdf](#SRC03)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

<a id="TERM.MATERIAL_DIFFERENCE"></a>
### 重大差异


足以影响受益所有权关系最终认定的人员、身份、权利状况或形成/终止时间差异。

容易混淆的边界：年月差异在影响关系认定时即可能重大。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="TERM.NON_MATERIAL_DIFFERENCE"></a>
### 非重大差异


不影响受益所有权关系最终认定的书写或权利状况差异。

容易混淆的边界：非重大不等于无需留痕或无需核实。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)

<a id="TERM.UNREGISTERED"></a>
### 经营主体未备案


系统查询不到备案主体记录的系统状态。

容易混淆的边界：不等于没有受益所有人。

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[受益所有人信息查询管理系统接口报文规范-V2.0.docx](#SRC06)

<a id="TERM.VERIFICATION_RESULT"></a>
### 核验结果


系统对比返回的一致、不一致或未备案状态，不替代业务识别判断。

容易混淆的边界：接口代码属于系统事实，实体结论需要业务核实。

同义称呼：cons/inco/unrg

审阅限制：该概念尚未补齐本轮要求的具体实例与反例。

依据：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[受益所有人信息查询管理系统接口报文规范-V2.0.docx](#SRC06)

### 问题 01｜哪些自然人符合受益所有人识别标准？（Q01）


主题：三条识别路径

本轮含义整理范围；具体确认状态见文末。

使用者：合规人员。结果用于：确定完整受益所有人集合

<a id="R01"></a>
#### 规则 01｜三路径并列识别（R01）


对应问题：问题 01 [哪些自然人符合受益所有人识别标准？](#Q01)

适用范围：所有法人和非法人组织的受益所有人识别

先核实什么：先收集所有权、收益权、表决权和控制权事实，再逐项检查三条标准。

如何判断：满足任一标准的自然人均纳入；同一人可同时满足多条标准。

可以得出什么：三条标准均不能确认时才可进入日常经营管理人员兜底。

例外与边界：无法证明的路径保持证据不足。

缺证时怎么办：相关证据缺失时保留证据不足状态，不以空值或猜测补全。

适用时间：持续适用；具体备案/金融机构场景分别按对应规范。

依据及口径来源：2024年第3号令第6条、2025年第12号令第8条及备案指南2.1.1-2.1.2。

规则依据索引：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

尚不清楚时：证据不足时保留未决，不把未知改写为否。

<a id="Q02"></a>
### 问题 02｜如何计算直接和间接股权、股份或合伙权益？（Q02）


主题：所有权穿透

本轮含义整理范围；具体确认状态见文末。

使用者：核实人员。结果用于：形成比例计算底稿

<a id="R02"></a>
#### 规则 02｜间接权益必须穿透计算（R02）


对应问题：问题 02 [如何计算直接和间接股权、股份或合伙权益？](#Q02)

适用范围：存在一层以上法人或合伙企业持有关系的主体

先核实什么：取得每一层股权或合伙权益比例及主体身份。

如何判断：逐层计算自然人最终拥有比例，达到25%以上时进入标准一。

可以得出什么：任一层缺失时不得按直接登记比例作完整结论。

例外与边界：控制协议可能使收益权或控制权另行适用标准二、三。

缺证时怎么办：相关证据缺失时保留证据不足状态，不以空值或猜测补全。

适用时间：关系实际生效期间。

依据及口径来源：金融机构客户识别办法第8条、备案指南3.1。

规则依据索引：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

尚不清楚时：缺少任一层结构时标记证据不足。

<a id="Q03"></a>
### 问题 03｜收益权或表决权与登记股权分离时如何识别？（Q03）


主题：收益权与表决权

本轮含义整理范围；具体确认状态见文末。

使用者：合规人员。结果用于：判断标准二及其证据

<a id="R03"></a>
#### 规则 03｜收益权与表决权单独判断（R03）


对应问题：问题 03 [收益权或表决权与登记股权分离时如何识别？](#Q03)

适用范围：登记股权与收益或表决安排分离的主体

先核实什么：取得分红、增值、表决或代理安排的有效文件。

如何判断：最终享有25%以上收益权或表决权即可满足标准二；同时控制的需并列记录标准三。

可以得出什么：没有生效协议、收益安排或表决证据时不得推定比例。

例外与边界：标准一已满足时仍应记录已发现的其他事实关系，不能删掉并列关系。

缺证时怎么办：相关证据缺失时保留证据不足状态，不以空值或猜测补全。

适用时间：以权利安排生效、终止时间为准。

依据及口径来源：2024年第3号令第6条、备案指南3.2.1和3.2.3。

规则依据索引：[中国人民银行令〔2025〕第12号（金融机构客户受益所有人识别管理办法）.pdf](#SRC02)；[受益所有人信息备案指南（第二版）.pdf](#SRC05)

尚不清楚时：没有有效协议或权益证明时不能推定。
