# Pass 2 — Question Discovery

使用已形成的 Statements 发现“业务上必须能独立回答什么”，Question 是覆盖轴，不是知识主体。

## 双路径

### A. Source → Question

从定义、义务、条件、例外、证据、时间中提出独立业务判断问题。

### B. Process → Question

从真实业务流程补查：谁发起、何时判断、事实从哪里来、证据冲突怎么办、缺证怎么办、变化后是否重做、谁确认、何时结束。

两条路径必须独立留下记录，不能先写最终问题清单再反填 QuestionDiscovery。

## 粒度

如果两个问题的前提、结果、缺证处理或时间任一会独立改变结论，则优先分开。文字相似不是合并理由。

候选问题只能进入 RETAINED / MERGED / OUT_OF_SCOPE / OPEN，并说明去向和理由。
