# 形式语义校核题：未运行完整推理器

本文件是手册勘误所依据的标准语义预期，不是本地41项应用测试的通过证据。没有部署相应推理器时，状态必须为未执行。

|情形|标准语义预期|生产补验要求|
|---|---|---|
|甲类和乙类互为子类|实例集合相同，不因循环自动不一致|检查是否意外等价，不把分类图约定冒充OWL定理|
|属性值域为自然人，组织进入该值域|可能得到额外自然人类型|分别在无互斥和有互斥时观察推论与一致性|
|存在持有人公理但显式记录缺持有人|开放世界下不必不一致|用数据约束单独检验记录完整性|
|两个不同IRI（国际化资源标识符）|名称不同不自动证明个体不同|明确同一性与不同性证据，不盲合并|
|甲类是乙类子类且与乙类互斥|甲类为空仍可能全库一致；要求甲类实例时产生冲突|区分类可满足性、实例与全库一致性|

依据：W3C（万维网联盟）OWL 2 Primer（网络本体语言第2版入门）、OWL 2 Direct Semantics（直接语义）、RDF Schema 1.1（资源描述框架模式）。链接见第一册来源索引。
