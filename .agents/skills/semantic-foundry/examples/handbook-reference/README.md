# 所有权与认定记录语义参考工程

版本：2.0.0。与《UBO与实际控制人本体语义工程样板》V2.0配套。

## 这是什么

一个以合成数据演示“来源记录→断言→采信事实视图→查询与受限所有权计算→可验证结果”的最小工程。所有姓名、组织、权益、证据定位、采信和覆盖声明均为合成，不对应真实客户。不是完整受益所有人识别、真实实体消歧、控制认定或业务审批系统。

## 运行

在本目录执行，要求Python（编程语言）3.11以上；本轮只实测3.13.5：

```bash
python -m pip install -r requirements.txt
python run.py
```

命令生成原始断言图、任务事实视图、所有权结果、显式应用合同检查及全部测试证据。本轮41项测试通过；具体范围以 `reports/verification.json`（验证报告）为准。`requirements-lock.txt`（依赖快照）记录本轮所有相关已安装版本，不是离线依赖包。

默认输入：T公司；2026-02-15业务日期；同日00:00 UTC（协调世界时）知识截止。普通股所有权结果：林甲42%、林乙28%、林丙20%、林丁10%。门槛命中仅为教学用普通所有权分支，绝不自动变成正式受益所有人。

## 单独运行标准约束验证

```bash
python -m pip install -r requirements-shacl.txt
python validate_shacl.py
```

pySHACL（Python形状约束验证库）当前未安装，环境网络名称解析失败，故本次标准SHACL（形状约束语言）验证记录为NOT_EXECUTED（未执行）。脚本返回码2，不使用替代校验器。依赖可用后，该命令执行正例、指定缺持有人负例及独立目标覆盖检查。主入口不会把其独立结果伪填为通过。

完整OWL（网络本体语言）一致性／类可满足性、ECP（企业认知平台）导入编译、独立业务复核与生产批准均未执行。

## 内容

- `model/`（模型）：本体、标准约束文件及不同业务记录表达例。
- `fixtures/`（合成输入）：来源、明确采信和覆盖声明。缺比例可保存，不会补造。
- `spec/`（合同）：实际合成模式、显式映射说明、执行配置、独立手算预期、29项具化和能力问题。
- `queries/`（查询）：直接股东及来源查询。
- `src/`（实现）：使用RDFLib（RDF处理库）与jsonschema（模式校验库），不自写通用本体或标准约束引擎。
- `tests/`（测试）：去重、冲突、身份、时间、比例、不完整和反例。
- `reports/`（证据）：实际运行结果。开发阶段的预期失败日志与当前通过日志分开。

## 核心边界

持股位置不等于来源记录；不同来源证据不增加持股数量；同名不证明同一主体。采信是明确输入，不由本程序评分或猜测。比例使用精确分数；只支持普通股同口径无环比例传递。未支持结构或缺数据时，报告局部结果和问题，不声称完整，不自动兜底。

显式应用合同检查不是标准SHACL验证：它只检查预期位置覆盖及三个必要字段。模型可解析不是逻辑一致性通过。文件摘要是源完整性证据，不是法律、业务或版权授权。
