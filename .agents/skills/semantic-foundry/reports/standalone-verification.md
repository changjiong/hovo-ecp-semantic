# 五技能独立使用修订

当前五个生产技能版本均为0.2.0；semantic-foundry 为0.5.1，保留为可选编排入口。此记录更新此前0.1.0建设记录中的安装与资源依赖结论，旧检查仍只证明当时版本。

## 已修改

- 五个技能的 manifest、入口、宿主接口与 README 不再要求安装或读取其他技能；不要求前序技能执行记录或 pipeline.json。
- 每个完整目录自带公共合同1.0.0、自己的输入输出 Schema、核对输入资产所需的 Schema，以及独立 validate_contract.py。公共 Schema 的 URI 通过包内 Registry 离线解析。
- 方法资料按技能随包固定；ECP 三技能各带 Kit 1.7 和职责所需工具。没有链接或加载回编排器目录的运行路径，不新增共享运行包。
- 输入可来自人工、其他工具或其他技能，资产身份、版本、摘要、来源与必要确认仍须成立。交付本阶段结果后结束，后续使用由用户决定。
- 各包 sources.json 记录固定快照摘要；合同或资料升级须显式核对受影响版本，不能从另一个技能目录自动取最新版。

这是目录资源闭合、结构和工具入口的验证，不是实际业务资产生成评估。沿用已安装 Python 3.12.3 验证环境，没有执行全新依赖安装、宿主发现/安装、模型触发评估、专家业务审查或 ECP 导入/编译/发布/Run。没有运行既有测试套件，也没有新增或修改测试代码。五个技能继续保持 scaffold 候选。
