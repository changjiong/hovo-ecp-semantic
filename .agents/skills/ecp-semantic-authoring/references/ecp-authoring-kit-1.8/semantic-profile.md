# Semantic Profile

文档类型：规范

文档状态：当前

权威范围：引擎公开承诺的语义边界

权威来源：`assets/semantic-boundary-v1.json`、编译器与一致性测试

适用版本：`ecp-semantic-boundary/1.0.0`

最后核验日期：2026-09-27

## 1. 规范定位

Semantic Execution Engine 实现一套有限、版本化且失败关闭的语义 Profile：

> RDF 1.1 + RDFS + OWL 2 RL 导向子集 + SHACL Core + 自定义声明式派生规则 Profile + 选定的 SKOS/PROV-O 模块

机器可读目标边界是 [`assets/semantic-boundary-v1.json`](../../assets/semantic-boundary-v1.json)。当前实现能力由 [`assets/semantic-capabilities-v1.json`](../../assets/semantic-capabilities-v1.json)声明。目标边界不等于当前能力，能力实现也不自动授予生产准入。

## 2. RDF 与图边界

- 接受 Turtle、N-Triples、TriG 和 N-Quads；
- 保留 IRI、作用域稳定 Blank Node、Literal 的词法／数据类型／语言身份；
- 支持默认图和命名图，并要求显式推理域；
- 精确整数和十进制不经二进制浮点近似；未知数据类型保持不透明；
- 非法 RDF、未声明网络导入和模型公理混入源数据均失败关闭。

## 3. RDFS 与 OWL

RDFS 使用有限输入／查询词汇上的标准规则和相关公理三元组，以最小固定点解释层级环；domain/range 是蕴含，不是验证。

OWL 只承诺机器边界声明的 RL 导向子集，包括命名类／属性等价、逆属性、对称／传递属性、属性链、命名交并与有限限制、可撤销个体等同性和声明的不一致检查。未声明位置或不支持公理必须在编译期拒绝，不得接受后静默忽略。生产提交遇到不一致时需要报告证明并拒绝。

## 4. SHACL

- 支持目标、节点类型、属性路径和边界资产列出的 Core 约束组件；
- 递归 Shape 以循环诊断拒绝；
- Pattern 使用固定的 SHACL 2017 / XPath 正则语义；
- ASSERTED、BASE、DERIVED、CHANGE、OUTPUT、PROVENANCE 六个检查点独立验证；
- SHACL 结果与提交许可分离；未提供 SPARQL/JavaScript 扩展。

## 5. 声明式派生 Profile

`ecp-declarative-derivation/1.0.0`只允许有限声明式关系、连接、分组、窗口、可达性和加权图算子。递归为正向、范围受限集合语义；否定需要分层和覆盖证明；聚合必须可撤销。表达式、精确数值、日期运算和显式 Cast 均受版本化有限矩阵约束，不执行任意代码。

`ecp-bounded-output-branches/1`提供`BRANCHED_ROWS`和`BRANCHED_LEFT_JOIN`。同一行或左连接的输出分支各自求值；true发出该分支，false不求值其输出表达式，UNKNOWN只保留该分支的可能输出及原因。非boolean条件为类型化UNKNOWN；资源耗尽使整个计算失败。最多16分支、合计128三元组模板及64输出绑定，原查询和64阶段上限不变。输出序号按分支/模板展开顺序固定；使用既有Rows/LeftJoin来源和证明，不共享运行身份或省略前提。条件常量按主查询图解析，输出常量按各输出图解析。机器边界摘要和运行时制品变化，ABI 6请求帧保持；旧检查点不自动兼容。

`ecp-finite-string-strip/1`提供`STRING_STRIP`：模型明确声明Unicode字符集与`ALL`或`ENDS`位置，保留字符串数据类型/语言及原输入身份，不执行模式匹配或隐式标准化。字符集最多64个标量/256字节，输入最多1048576字节，输入字节数乘去重字符数最多4194304；缺绑定、非字符串为类型化UNKNOWN，资源耗尽为不可吞掉的错误。边界摘要及运行时制品随此扩展变化，ABI 6请求帧不变；旧检查点身份不自动兼容。

有限网络子Profile`ecp-bounded-network-fold/6`的算法及端口以机器边界为准。集合聚合阈值闭包只从明确seed求最小固定点，保留精确合计、严格唯一最大值和blocked条件；不把无seed环当事实，不解释业务标签。逐根frontier端口只切断其他边界节点的入向经济边，当前root豁免；独立声明的归属和结构化控制证据保留。严格数值折叠对当前root逆向可达的已解循环给出类型化范围标记与信息性诊断，不改变数值，也不产生UNKNOWN成员域。解限控制闭包独立声明目标边界与源节点限制，以当前actor/root的有界简单路径判断解限及上市证据；decisive只决定节点闭包，不自动绕过首层门禁。简单路径暴露在明确节点范围内对所有不重复节点的路径精确求和，不作循环调整或claim归属；路径数量及计算预算耗尽失败，不截断成功。[消费合同](../contracts/consumer-protocol.md)定义成员输出、边界、证据及兼容身份。

`ecp-bounded-window-order/1`在既有`WINDOW`主排序后接受最多8个`secondaryOrderBy`表达式/方向次键，按RDF值逐项比较；数值保持精确，不按词典编号或隐式字符串转换决定已声明次序。所有声明键相等才使用稳定事实身份。缺失或本身不可排序的键使整个分区UNKNOWN，单行分区也必须验证；比较遇到不相容值同样UNKNOWN，资源失败不截断成功。默认次键为空且序列化时省略。证明包含同分区全部竞争绑定及来源版本；无关分区不加入。表达式常量沿用主查询图别名域。ABI 6帧不变，机器边界及运行时制品身份变化；不声称旧检查点兼容、局部成本或正式性能通过。

## 6. UNKNOWN、质量与证明

- UNKNOWN 表示缺少安全结论，不能归约为 false；
- 网络数值UNKNOWN保留已声明root/actor身份和来源，明确策略拒绝的空结果域不被扩大为未知成员；列索引及同阶段闭包复用不得减少可能匹配或原因；
- 输入覆盖、上游不确定、质量违反、语义不一致和资源失败是不同状态；
- 事实身份与 Support 身份分离，一个支持撤销不得删除仍有其他支持的事实；
- 证据支持充分见证与全部贡献两种模式，固定状态分页并可递归展开到源行版本；
- PROV-O 是按需投影，不要求预物化所有路径排列。

## 7. 词汇模块和生命周期

SKOS/PROV-O 只在发布显式选择并锁定模块字节时参与编译。引擎生命周期 Profile 目前包括 `NONE` 与 `OCCURRENCE_REVISION_V1`，且不按领域、Workspace 或 Release ID 硬编码分发。动作策略属于模型身份；动作意图生成、事务和外部投递由宿主负责。

## 8. 扩展规则

任何语义扩展都必须同时修改机器边界、编译器／内核、能力资产、合法与拒绝用例、增量／删除／模拟／恢复／证据测试以及兼容性身份。单纯解析一个新字段不能构成支持声明。
