# reports

本目录保存 domain-model 1.0.0 之前的研究、评估和交付证据。

这些文件是历史材料，不是当前生成合同、当前 Prompt（提示词）或 PRODUCE（创建）的语义输入。

当前实现只以以下入口为准：

- ../SKILL.md
- ../prompts/01-knowledge-to-domain-model.md
- ../references/business-modeling.md
- ../references/business-model-contract.md
- ../contracts/business-domain-model.schema.json
- ../contracts/coverage.schema.json

历史报告中出现的 Domain DSL 1.x/2.x、Rule expression（规则表达式）、Process（流程）、StateMachine（状态机）和 evaluate（求值）均已退出 1.0.0 当前设计。
