# 真实技能生成评估

这一层与关键词路由、文档存在性及工具单元测试分离。当前状态为未执行。

使用 `tasks.json` 的三种任务，固定材料、既有资产、模型与工具权限；分别用旧版和新版技能运行。加载实际入口和按需手册并记录摘要、读取轨迹、澄清次数、产物和实际工具调用。不要将答案复制进任务上下文。

在运行前独立固定验收要求，关注关键语义错误、事实/假设边界、能力问题可执行性、禁止推论、平台适配差异和不必要的用户打断。允许结构不同但满足同一契约的合理模型；不要求图形完全相同。失败应引用产物片段与反例，不接受自评高分替代证据。

记录实际执行模型、输入、技能与手册摘要、输出路径及评审人。没有真实调用时保持 `NOT_EXECUTED`（未执行），不得把测试用例JSON（轻量数据交换格式）存在当成生成评估通过。

所有权参考工程41项只证明参考代码，不直接证明宿主模型或平台；平台候选编译与运行是第三层独立证据。
