# 三册规范的读取与版本索引

规范源为 `handbooks-v2/` 下三份原始Markdown（轻量标记文本），原字节来自用户已交付V2.0压缩包。`source-manifest.json`记录文件名、长度和摘要。没有更改原文或将本技能扩展冒充原文。

|触发问题|源章节|必须形成的信息|
|---|---|---|
|新场景与范围|第一册§2、§7|能力问题、排除项、最小切片|
|类、关系、角色怎么选|第一册§3|六项概念检查、简单与多元关系选择、反例|
|身份/更名/重复记录|第一册§4.1；第二册§5.3|来源标识与现实身份的对应，未知匹配不盲合并|
|有效期、追溯更正|第一册§4.2；第三册§5|业务时点、知识截止、采信与替代|
|比例、金额、计量|第一册§4.3|单位、分母、尺度、精度、舍入边界|
|来源与证据|第一册§5；第二册§5.4|断言和事实视图之间的显式采信契约|
|规则/计算/本体边界|第一册§1.2、§6|描述与执行责任，允许推论及不支持能力|
|原项“7+1”“29句话”|第二册§3；第三册§8—9|原项不改写，解释另列，适用或不适用有依据|
|有限澄清|第二册§2|事实/假设/待决策/必要输入分离|
|写测试与报告|第二册§5—7|精确预期、禁止结果、目标覆盖、执行状态|
|发布与复用|第二册§8；第一册§8|清单、权限、依赖与变更影响|
|所有权参考实现|第三册§3—11|模式及反例；明确普通股无环和合成输入边界|

本技能的执行检查表引用这些章节，不是并列的第二份权威手册。更新手册时先核对来源，再列受影响规则和测试；不能只改版本字符串。

`examples/handbook-reference/`保留第三册附属工程及其历史报告。历史报告仅为来源档案，不计入0.3.0新测试结果。执行时使用 `--output` 写到新目录。

资料边界：用户本次授权内部交付与使用，不等于全部第三方引文的公开再分发授权；本次不上传公开仓库。当前三册也不替代特定机构制度与授权确认。
